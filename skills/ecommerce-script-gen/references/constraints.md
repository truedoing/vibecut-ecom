# 写作约束（动笔前扫一眼，不用逐条对照）

## 结构
- 上来就是钩子（段 1），冲突放第 1 秒。全片两段：0–15s AI 钩子 / 15–60s 混剪 + 旁白。
- 段落角色：`hook` / `pain` / `proof` / `trust` / `price` / `cta`；连续同角色别超 3 段。
- 钩子段不举证、不念数值 / 成分 / 功效；人物只在钩子出现，之后切旁白。
- 创意（`creative_brief`）不外溢到证据、信任、价格、转化。

## 举证
- 层级：L1 已核实数值 ＞ L2 体感 / 用量画面 ＞ L3 带出处的折算 ＞ L4 场景。
- 场景型举证 1–2 条就够；连续 proof 超 3 段时插一段 `trust` 打断。
- 数值只从品类包 `verified` 事实取，`null` 用占位符（【条数】【到手价】【日期】），不编。

## 语速与时长
- 按档位：抖音 4.5 / 视频号中老年 3.8 / 中年女性 4.1 / 给妈妈买 4.3 字/秒，顶层写 `speech_rate`。
- 60 秒片 ≈ 215–236 字。别硬撑满，剧情型宁短勿松。

## AI 镜头
- ≤ 2 条，默认都在前 15 秒钩子段。默认**一条 15 秒**跑完四拍，内部切 4 个分镜
  （每镜 2–5 秒，切点按台词分句给）；两条只在「主镜头 + 产品特写」确有必要时才用。
- **双人钩子走正反打，不追求双人同框**：一条视频里 A 拍指责、B 拍反抗、A 拍赌气、B 拍打脸，
  每镜只有一个人露脸。双人同框脸权重减半，还容易冒第三人。
  提示词必须加一句「A 自始至终是 @Image1、B 自始至终是 @Image2，五官不要混淆，不要第三人」。
- **参考图用单格人物图，不用整张多联定妆照**：多联会被读成并排构图，人脸权重被稀释。
  角色卡 `portraits.ref_video` 就是为此裁好的左格单图。
- **音色传样本，不预生成台词**：把角色 `voice_ref_5s.mp3` 当 @Audio 参考传进去，
  台词用 `{}` 写在提示词里让模型念，音色由样本锚定。省一步、口型自然。
  样本裁 5 秒——完整 voice.mp3 两条合计会超参考音频的总时长预算。
  风险：中文台词可能吞字或口音飘，**跑一条先看**；念不清就回退「voiceclone 预生成台词音轨 +
  @Audio 整轨对齐口型」（`gen_voice.py --clone --style`）。
- 提示词符号：`{}` 台词 · `( )` 音乐/音效 · `<>` 音效。一镜只给一个运镜；
  动作按身体部位+程度+过渡写；情绪写物理表现（"嘴角一撇"）不写抽象词（"不耐烦"）。
- **AI 生成的产品必须虚焦**：罐子只给轮廓/背景虚焦，标签不可读——AI 画不出真包装，
  露了就是假包装，混剪接真罐穿帮。负面词写「清晰可读的产品标签」。
- `negative_prompt` 经验值：主镜 `字幕，文字，logo，水印，第三人，多余手指，五官混淆，男女音色互换，清晰可读的产品标签，正脸看镜头`。

## 合规
- 普通食品四类红线：疾病功效、无依据虚假比较、无认证宣称、虚假价格稀缺；
  外加过敏原反向宣称（安全底线）。「保健品」永不进文案。
- 中老年红线：降三高 / 清肠 / 排毒 / 治便秘 / 增强免疫 / 防癌 / 延年益寿 /
  更年期 / 补钙 / 改善睡眠 / 医生推荐 / 营养师认证 / 央视上榜 / 秘方，不进。
  文案只讲口感、方便、配料、价格、习惯。
- 中年女性额外：抗衰 / 抗氧化 / 显年轻 / 去皱 / 淡斑 / 美白 / 补气血 / 调经 /
  减肥瘦身 / 改善睡眠 / 缓解疲劳 等不进。「关爱自己」落在**时间与允许**上，
  不落在身体改善；痛点命名命名心理状态，且不能说喝了能改善。
- 健康暗示落到场景 / 口感 / 配料 / 数字 / 产地。有出处的换算加「按…折算」即可用，不必删。

## 别做
- 别问预算、别算成本推演；别复述准则正文，一句话指向本文档即可。
- 别把创意铺成整片剧情；钩子结束就切旁白。
