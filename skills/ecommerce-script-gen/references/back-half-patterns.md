# 后半段不是模板（15–60 秒的五个可变量）

> 起因（2026-11-04 张老师指出的真问题）：T2_004 与 T2_005 的**后半段一字不差**。
> 钩子换了型，第 16 秒之后还是那九句。跑 `scripts/back_half_ideas.py` 一验就露馅——
> 两条指纹完全相同：`产地|产地→吃法→数值→配料|拍一发四折算`。
> 根源是 SKILL 只给钩子做了「六型 + 12 冲突原型」的轮换，后半段是一张锁死的表。

## 一、先把边界划清：什么必须不变

**事实层锁死**（变了就是自相矛盾，甚至违规）：

| 类别 | 锁定内容 |
|---|---|
| 配料 | 三样：脱皮油莎豆、冷榨油莎豆油、食用盐；没有白砂糖 |
| 数值 | 每 100g：能量 2449kJ / 蛋白质 3.9g / 脂肪 44.9g（单不饱和 33.1g）/ 碳水 38.1g / 膳食纤维 9.2g / 钠 95mg / 维E 7.32mg |
| 规格 | 150g / 9 个月 / 开封冷藏 2 周内吃完 |
| 产地 | 新疆图木舒克 / 135° 低温慢烘 |
| 价格 | 日常 59.9 / 直播 99.9 拍一发四 / 折合约 25 一罐（三个数互相咬死，只念其中两个会显得在藏） |
| 红线 | 过敏原反向宣称（生产线也加工花生芝麻坚果）、疾病功效、无认证宣称、虚假稀缺 |

**表达层全部可变**：先说什么、拿什么画面证明、这笔账怎么算、最后劝谁买。

一句话：**锁值不锁序，锁事实不锁说法。**

## 二、五个槽位

### 槽位 1 · 卖点主角（六选一，这一条主打谁）

| 代号 | 主打 | 可用证据 | 适合的人 |
|---|---|---|---|
| 配料 | 干净、三样、没有白砂糖 | 翻罐读配料表 / 三样倒出来并置 | 给家里买、怕添加的中年女性 |
| 吃法 | 拉丝、抹开一层、咸甜口 | 舀酱提拉 / 抹面包成品 | 早餐场景、第一次听说的人 |
| 数值 | 纤维 9.2g、维E 7.32mg | 数值特写 / 包装背面 | 理性派、比价前先看成分 |
| 产地 | 新疆图木舒克、135° 慢烘 | 航拍 / 沙漠 / 颗粒手摊 | 认产地、认“土里长出来的” |
| 规格 | 150g、开封两周吃完、一罐吃多久 | 开罐 / 冰箱 / 桌面尺寸对比 | 怕浪费、吃过“买回来放坏”的亏 |
| 价格 | 拍一发四、合一罐 25 | 罐子堆 / 手持罐 / 价格字幕 | 已经被前五项说服、就差一步 |

### 槽位 2 · 举证顺序（先回答观众心里哪一句）

常见四条链，别默认用第一条：

1. `配料→数值→吃法` 稳，最保险，也最像说明书
2. `数值→配料→吃法` 理性开局，适合投中年男性/给父母买
3. `吃法→配料→数值` **先勾口欲**，短视频最吃这套
4. `产地→配料→吃法` 故事前置，适合做“土特产”叙事
5. `规格→吃法→价格` 实用前置，适合怕浪费的人群

### 槽位 3 · 证据形态（同一个卖点，六种证法）

翻罐读配料表 · 三样倒出来并置案板 · 数值特写 · 撕封条开罐 · 抹开成品镜头 · 生产线灌装

> 同一卖点在不同片子里换证法，比换台词更有效——观众记的是画面。

### 槽位 4 · 数字处理

原值直读 / 折算单罐价 / 对比日常价 / 换成人话（**必须有出处，没有就留占位符**）/ 不念数字只打字幕

### 槽位 5 · 逼单与 CTA

拍一发四折算 · 低门槛先一罐 · 转给家里做饭的那个人（转发/代买）· 场景提问互动（“你家早餐吃什么”）
· 风险逆转（开封两周吃完、不浪费）· 先转再拍

**中老年视频号默认「转发/代买」路径比「直接拍」更自然**；直接拍适合已被完整说服的收尾片。

## 三、组合纪律（五条，前三条是硬约束）

1. **指纹不撞**：`卖点主角 | 举证顺序 | 逼单` 三元组，与**近 3 条**不得相同。
2. **主角不连用**：相邻两条的卖点主角必须不同。
3. **开场不连用**：举证顺序的第一项，相邻两条不得相同。
4. **每条只主打一个卖点**，其余四个当配角各给一句，别五个都使劲——五个都使劲等于没有卖点。
5. **举证配额仍受约束**：场景类（L4）最多 1–2 条；连续三段 proof 要插一段 `trust + T1` 打断。

## 四、怎么验

```bash
# 列槽位 + 看已用指纹 + 拿 3 个未用组合
python3 scripts/back_half_ideas.py --pack packs/{品类}/category-pack.json --scripts-dir <产物目录> --top 5

# 定稿前校验候选组合是否撞近 3 条
python3 scripts/back_half_ideas.py ... --check "配料|规格→吃法→价格|低门槛先一罐"
```

定稿后把三元组写进脚本 JSON 顶层 `back_half`，下次查重直接读字段，不用再靠文本推断：

```json
"back_half": {"lead": "配料", "chain": ["配料", "数值", "吃法"], "close": "低门槛先一罐",
              "proof_style": ["翻罐读配料表", "数值特写", "抹开成品镜头"],
              "number_treat": "原值直读"}
```

## 五、反例（自己踩过的）

- **T2_004 / T2_005 同指纹**：只换了钩子型（真香 → 误解），后半段整段照抄，第 16 秒起完全一样。
  控制变量做实验可以这么干一次，量产就是同质化。
- **把「变」理解成「换词」**：同一个顺序、同一个证法，只把「干干净净」改成「没添加」——
  观众感受到的是同一条片子。要变的是**顺序和证法**，不是形容词。
- **五个卖点平均分配**：每段都提一嘴，结果没有一个立得住。主打一个，其余当背景。
