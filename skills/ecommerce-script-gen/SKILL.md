# ecommerce-script-gen

给一个轻食品类写一条 60 秒带货短视频脚本。产出两份：`{id}.json` + `{id}_拍摄执行单.md`。
**产物固定落 `runs/{品类}/{task}/`**（跨会话恢复的唯一依据，别再落 cwd——T2_005 因此丢了全部中间产物）；
调用方显式给了别的目录才改。

> **本技能不是入口。** 调度、进度、多线并发、门禁与状态台账一律走 `ecommerce-supervisor`；
> 本技能只负责「写脚本与两道自查」，不判断「现在该不该做、做完该接谁」。

## 怎么用（三种话术）

| 你想干什么 | 这么说 | 做到哪一步停 |
|---|---|---|
| **只要钩子创意** | `用 ecommerce-script-gen 给 虎坚果酱 出 3 个钩子创意` | 读品类包 → 查重 → 给 3 个候选（各带五维分、风险、第一句台词）。**不落盘、不写整片、不生成视频** |
| 写一条完整脚本 | `写一条 X 的脚本，角度用 Y 型，钩子用候选 2` | 两份产物 + 两步自查（validate + prompt_lint） |
| 只体检提示词 | `跑一下 prompt_lint 检查 TaskN` | 只报 E/W/I，不改文案 |

**只要创意时，第一件事是跑供给器**（它给边界，不给灵感）：

```bash
python3 scripts/hook_ideas.py --pack packs/{品类}/category-pack.json --scripts-dir <产物目录> --top 6
```

它只做三件机器能做的事：从品类包抽 **4 个拒绝理由槽位**（不遗漏）、从
`references/hook-patterns.md` 读 **12 种冲突原型**（单一真源）、扫已有脚本的
`hook_pattern` **查重**（不重复）。输出的是候选池骨架；**台词、四拍、评分由 Agent 填**——
出彩是编剧的活，技能管的是不遗漏、不重复。

**门禁顺序**：候选 → 人挑一个 → 写全片 → `validate.py` → `prompt_lint.py` → 才交给出片。
`prompt_lint` 有 E 就停。3 元一次的门票（15s/480p 实测），写提示词的人要自己先把门关好。

## 片子结构模式（动笔前定，写进顶层 `video_structure`）

两种模式，生成时二选一。**结构是第 0 号决策，开场必须让用户明确选定，不许静默默认**：
它决定要不要多出一条 AI 副视频（约 2 元）、转化段怎么写、旁白怎么分段、mix 要不要接
`--tail`——走到一半改结构＝钩子之后的活全部重做（T2_005 实翻案一次）。
用户没说时问一句「单钩还是主副双塔？」，定下来的值写进 run 状态文件当第一个 artifact
（`structure`，无 depends_on），脚本及以下全部 `depends_on` 它——改结构自动把下游标 stale。
另外，**双塔结构影响文案本身**（转化段单独成段、逼单句要有设计感），所以必须在动笔前定，
不能写完再补。

**`single_hook`（单钩子，默认）**

```
0–15s  │ 钩子 · AI 生成
       │   冲突抓眼球，全部人物在这 15 秒出场；产品只当道具露脸
       │   不念卖点 / 数值 / 功效；人物出镜说对白（音画一体）
15–60s │ 混剪 + 旁白
       │   画面全是素材，人物不再出现
       │   证据 → 信任 → 价格 → 转化逼单
```

**`hook_plus_convert`（钩子 + 转化双 AI）**：在 single_hook 基础上，把**最后 2–3 句
（价格 + 逼单 CTA）从素材混剪升级为一条 AI 副视频**（8–10s，480p 约 2 元）。适用：
转化段画面平淡、或逼单句需要一个有设计感的收尾镜头。中段（证据/信任）仍走素材——
AI 只补最值钱的头尾，不铺中间。

**转化段副视频四条硬规则**（2026-11-05 张老师定）：

1. **不露脸**。角色在钩子里是"用户"，到转化段变"推销人"＝人设漂移，观众警觉。
   只出手 / 身体局部 / 或干脆无人物（纯产品动态镜头）。
2. **副视频必须做素材做不到的事**（2026-11-05 张老师纠偏：v1 手部开罐/舀酱/拉丝
   桌拍素材里全是，AI 重拍＝贵一点的桌拍，不促转化）。AI 的长处＝转化机制：
   物体变换（1 罐变 4 罐＝拍一发四视觉化）、金色价格字浮现、促销光效、
   接钩子剧情的动作（递面包接住"再给我一片"）。纯产品展示镜头留给素材。
3. **文字特效可由 AI 生成**（张老师 2026-11-05 定，减后期工作量），但限短数字/短语
   （如「拍1发4」「到手25/罐」），每条 ≤2 处；**长文案仍走后期叠**。
   出片后人审第一件事查错字——AI 写中文字必错字，抽卡到对为止。
4. **涉及产品必须挂产品参考图**：`ai_shots[].product_ref` 指向
   `assets/{品类}/product_refs/` 的主参考图，提示词写明「瓶身外观与参考图一致」。
   AI 自由发挥的产品 = 别人的产品（标签必画错）。
   **标签防穿帮两条**（2026-11-05 首次出片实测）：①产品做**前景主体**时，让手
   **握住瓶子大部分**——手挡住标签，AI 复刻不准的文字就不穿帮；②产品做**背景**
   （多罐排开、浅景深虚化）随便用，虚化了没人看标签。T2_005 AI-2 实测：金字特效
   一次全对，但罐身标签特写定格处 "Cyperus Eescslaus" 乱码可见。
5. **声音仍走旁白**（后期 TTS），不为副视频单独生成语音——副视频里人物不开口，
   就没有口型问题。

「创意」只指钩子这 15 秒。默认模式从元素库抽一句钩子；创意模式由用户给
`creative_brief`（人物 / 冲突 / 反转 / 产品道具 / 声音）。钩子之后的两种模式完全一样，
共用同一份产物、同一套合规红线。**别把创意铺成整片剧情。**

**但 15 秒之后不是模板。** 钩子在轮换、后半段照抄，是 2026-11-04 被指出来的真实缺陷：
T2_004 和 T2_005 的后半段一字不差，从第 16 秒开始眼熟——完播掉在价格段之前，平台也判同质化。
后半段有五个槽位可独立变（卖点主角 / 举证顺序 / 证据形态 / 数字处理 / 逼单 CTA），
**锁值不锁序**：事实层（配料三样、每 100g 数值、规格、产地、三个价）一个字不许改，
先说什么、拿什么画面证明、怎么算这笔账全部可以换。细则见 `references/back-half-patterns.md`。

### 钩子是微剧情，不是三句话

80 字左右 / 10–15 秒，四拍跑完，缺一拍就没张力：

| 拍 | 干什么 | 例（真香） |
|---|---|---|
| ① 指责 | 有人挑刺，具体到物 | 上个月那罐还没开封，柜子全是你的瓶瓶罐罐 |
| ② 反抗 | 被挑的人不能软，要顶回去 | 我花自己的钱，好东西我就是要买，有本事你别吃 |
| ③ 赌气 | 把话说到绝处，给反转留空间 | 我不吃，一口都不碰 |
| ④ 打脸 | 换场景，用动作收，不用解释 | 自己抹第二片，被一句「你不是不吃吗」戳穿 |

- **冲突要显性**：双方都得开口，不能一个人骂、另一个人沉默
- **反转靠动作**：手伸过去、又抹一片，比台词有力
- **争执段语速可到 5 字/秒**（抢话本来就快），别按 3.8 硬压
- 钩子里不念数值、卖点、功效——那是混剪的事

### 心理动线检查（写完钩子先过一遍，2026-11-06 张老师定）

钩子是给观众的一个**心理承诺**，CTA 是一个**行动召唤**，两者必须串成同一条情绪弧：
**钩子承诺 → 中段用什么化解 → CTA 行动**。断点要么补桥，要么换钩型——
这条检查是写稿纪律，validate 查不了语义，人审也常拿不准，方法论必须前置。

**T2_006 实例（正面教材＋补桥）**：钩子「瞒着闺女偷吃」（羞耻/节俭）与 CTA「给家里添一罐」
（开放/添购）看似冲突，但价格段 25/罐恰好是化解「怕被说乱花钱」的钥匙——补半句
「才二十五，不用藏着掖着」弧线就闭合了。**冲突可以留，甚至是资产；没闭合才是错。**

检查三问：①钩子承诺了什么情绪？②中段哪一段负责化解它？③CTA 的行动和这个化解
接得上吗？三问答不全就补桥（优先）或换钩型。

### 情绪档跟随钩子（给 narration 的话，2026-11-06 定）

钩子段什么情绪，后半段旁白就延续什么情绪落点：悄悄话/自白钩子 → normal 档 + 标签往回收；
争执/真香等高冲突钩子 → 才允许 high 档。别让「压低声的悄悄话」后面接「激情叫卖」，
同一个嗓子前后判若两人（T2_006 实测翻车点）。

## 第 0 步：先盘素材，再定结构

**画面从素材里长出来，不是写完文案再编画面。后半段能铺几段，由库存决定。**

```bash
Q=skills/ecommerce-asset-analysis/scripts/query.py
I=assets/{品类}/asset_index.json
python3 $Q $I --list                    # 有哪些文件、各多少镜头
python3 $Q $I --catalog assets/{品类}    # 人读目录，每镜头一行
python3 $Q $I --usage texture,hand --min-len 3 --limit 8   # 按条件取镜头
```

索引不存在 → 先跑 `ecommerce-asset-analysis` 技能；连原片都没有 → 出「素材采集清单」
（要什么镜头、几秒、用在哪段），按清单写，缺项标「待补」。**任何情况下都不许凭空编画面。**

**库存 → 能铺什么**（先数一眼，别硬凑）：

| 库存富余 | 能铺的段 | 例子（虎坚果酱实测） |
|---|---|---|
| origin 产地/田间/沙漠 | 溯源：原料哪来的、怎么收的 | 153 个，够铺两段 |
| hand 使用动作 | 吃法：抹 / 拌 / 蘸 / 空口 | 62 个 |
| texture 酱体质地 | 口感：舀起来什么状态、抹开什么样 | 37 个 |
| process 生产线/灌装 | 信任：怎么装进去的 | 35 个 |
| product 罐体标签配料表 | 依据：翻罐背、看配料、看克数 | 17 个，**少，别连用** |

某一类少就少写那段、靠口播补。**宁可段数少、每段实在，不要为凑结构硬塞。**

## 输入：品类包

读 `category-pack.json`。定位顺序：调用方给的路径 ＞ 当前工作目录 `packs/{品类}/`
＞ 云端「品类包/{品类}/」。找不到就问一句要哪个包，**不要自己编产品事实**。

| 读什么 | 怎么用 |
|---|---|
| `meta.review.human_review` | 不是 `passed` 就只出草稿 |
| `product_facts` | `verified && usable_in_copy && !blocking` 的 `value` 才进口播；`null` 用 `placeholder`，不编数字 |
| `selling_point_map` | `usable_rewrite` 是写作起点，`condition` 是前提，`status: blocked` 不用 |
| `compliance_ext` | 品类专属红线，动笔前扫一眼 |
| `elements` | 钩子 / 痛点 / 举证 / 信任 / 金句 / 转化，直接拿来用 |
| `elements.audiences` | **有就按包里的人群写，不再套平台默认档**（人群由标的决定：书=父母/自我成长/代际）；钩子条目的 `audience` 决定这条给谁看 |
| `pending` | `blocking` 项进执行单「待确认」，不进口播 |
| `asset_index` | 包里这块只登记状态；真实镜头走 `assets/{品类}/asset_index.json` + query.py（见第 0 步） |

其余字段（`conflicts`、发布标记等）不用管。

**语速档位**：抖音 4.5 / 视频号中老年 3.8 / 中年女性 4.1 / 给妈妈买 4.3 字/秒。
脚本顶层写 `speech_rate` 声明档位。视频号中老年钩子认人认事认场景（菜市场、遛弯、
配料表），转化走「让孩子们帮你看一眼」；中年女性钩子要「认出自己」，转化落在「允许自己」。

## 步骤

1. **定角度 + 定结构模式**：六型选一（人群切入 / 痛点命名 / 反常识 / 场景 / 算账 / 信任溯源）。
   换角度就是一条新脚本。`angle_type` 写清是什么即可，不用硬套枚举。
   同时定 `video_structure`（`single_hook` 默认 / `hook_plus_convert` 双 AI），
   双结构时最后 2–3 句标 `shot_source: AI` 挂尾段 `ai_shot_id`。
2. **定钩子**（先出创意，不要等灵感）：三步走——
   ① 先跑 `scripts/hook_ideas.py`（见「怎么用」），它列出 4 个**拒绝理由槽位**、
      12 种原型、以及**已用过的格子**；把槽位里的包内原料改写成真人会说的口语。
      连用 ≥3 条的原型会被直接停用——这不是建议，是库存纪律；
   ② 从 `references/hook-patterns.md` 的 12 种冲突原型里挑，与拒绝理由交叉；
      只挑没占用、且文档标了「适合」该槽位的组合；
   ③ 按五维评分卡打分，**给 3 个候选**（各带分数与风险提示）让人挑。

   不要只给一个方案，也不要问"你想要什么创意"——给三个，人挑一个只要 15 秒。
   定下来的原型记进钩子段的 `hook_pattern` / `hook_reject_reason`，下次靠这两个字段查重。
   冲突放第 1 秒，钩子段不举证，人物只在钩子出现。
   卖点过三自测：需要感 / 可信度 / 唯一性（竞品也能说的就是废话）。
3. **写口播 + 同时挂画面**：段 1 是钩子，其余按一条**讲述链**铺，总段数 ≤ 15，按语速控字数。
   钩子段 `shot_source: AI` 挂 `ai_shot_id`；混剪段一律「旁白」，人物不再出现。

   **动笔前先定后半段组合**，别顺手照抄上一条：

   ```bash
   python3 scripts/back_half_ideas.py --pack packs/{品类}/category-pack.json \
     --scripts-dir <产物目录> --top 5          # 已用指纹 + 未用组合
   python3 scripts/back_half_ideas.py ... --check "配料|规格→吃法→价格|低门槛先一罐"
   ```

   定下来的三元组写进脚本顶层 `back_half`（`lead` / `chain` / `close` / `proof_style` /
   `number_treat`），下次查重读字段，不靠猜。**近 3 条同指纹直接重排。**

   **混剪不是一句一个类型地贴标签。** 每句都要回答观众心里正在问的那句：
   钩子冒出的疑问（「这什么酱」）→ 是什么 → 凭什么 → 会不会又踩坑 → 还能怎么用 →
   值不值 → 该转给谁。写成一条人话；`section_role` 只是内部标记，不念出来。
   混剪与钩子弱相关即可，不必强行呼应，但**句与句之间要接得上**。

   **每个混剪段挂 1–3 个真实镜头**（`visuals`），写完口播立刻挂，别事后配图：
   `shot_id` 用 query.py 输出的（如 `C5396#0`），带 `in`/`out` 秒数。
   **挂镜头前必须先跑 query.py 按句检索**（`--usage` / `--kw` / `--category`）——
   凭记忆挑 = 永远只用熟悉的十几个镜头，素材库 200+ 镜头等于白建（T2_005 v2 实翻车：
   210 镜池只用 11 个，其中 7 个同批桌拍）。检索结果里优先挑**近 3 条片没用过的**，
   语义强绑定的镜头（拉丝、抹面包）才允许跨片复用。
   素材镜头普遍比需要的长（实测均值 13.5s、最长 85s），**一律写「取 X–Y 秒」，不要整段用**。
   60 秒片子混剪段 10–20 个镜头、平均 3–5 秒一个，别切成碎渣。

   **音画同步三条**（这是混剪不翻车的底线）：

   - 口播提名词 → 画面必须给到。说「罐背配料表」就必须是 product 特写，不能配航拍
   - 口播提动作 → 画面给动作。说「抹开」就必须有 hand/texture 镜头
   - 口播句的起点 ≈ 镜头入点。画面比话晚两秒，观众会觉得错位

   **反单调三条**（防止后半段像 PPT）：

   1. 相邻两个镜头的用途主类不能相同（连着三个罐子摆拍＝灾难）
   2. 连续 3 个镜头里至少 1 个是特写或近景
   3. 每 10 秒画面必须变一样东西：景别 / 主体 / 场景，三者至少变一个
      （素材库常只有一个场景，别硬求换场景；桌拍内部从罐体特写→舀酱→抹面包就已经在动了）

   缺画面：标 `missing: true` 并写替代（用哪类镜头顶），**不许编不存在的素材**。

   **钩子与混剪的衔接**：钩子最后一镜（餐桌/手/人脸）→ 混剪首镜头，用产品特写或同场景
   转场接住；不要从室内对话直接切到航拍沙漠。
4. **定 AI 结构**（和写口播一起做，别事后补）：默认**一条 15 秒**跑完钩子四拍，
   内部切 4 个分镜、正反打各露一人；≤ 2 条只在确需补产品特写时才用。
   `hook_plus_convert` 模式再加**尾段一条 8–10 秒**（AI-2，转化段，按上面四条硬规则写）。
   定 `sound_plan`（双人对白 / 单人自述，是否留旁白）。
   **人物与场景引用资产库**：`character_ref` / `env_ref` 填 `ch_NNN` / `env_NNN`
   （双人写 `ch_001,ch_002`），用 `ecommerce-ai-assets` 的 registry.py 查库，
   没有合适角色就先建卡再回来写。尾段副视频若纯产品/手部，`character_ref` 可为 null，
   但 `product_ref` 必填。
   **提示词与音色**：`prompt` 写满（参考图分工 + 分镜 + 台词 + 场景光线 + 约束），
   `prompts_pending: false`；台词不预生成音轨，传角色 `voice_ref_5s.mp3` 作音色参考。
   钩子里的人物可以当后半段解说（声音在、画面不在），比换一个人念更像回事。

   **写完立刻跑提示词体检**（下一节），有 ERROR 不许交出去。这是 3 元一次的门票（15s/480p 实测），
   写提示词的人要自己先把门关好。
5. **出两份产物**，格式见 `references/output-spec.md`。
6. **两步自查**：
   - `python3 scripts/validate.py {id}.json` —— 结构 4 条红线
   - `python3 scripts/prompt_lint.py --json {id}.json --reverse-word <反转词>` —— 提示词能不能出片

## 合规（商家视角：卖点尽量用，只换风险谓语）

普通食品不碰：疾病功效、无依据虚假比较、无认证宣称（有机 / 农残 / 蓝帽子）、
虚假价格稀缺，外加过敏原反向宣称。**「保健品」三字永不进文案**，用「那些瓶瓶罐罐」指代。
身体改善类说法落到口感 / 方便 / 配料 / 数字 / 场景；厂商原话尽量保留，只去风险谓语，
**不要换成另一个不相干的卖点**（「饱腹感强」≠「一勺能抹满一片面包」）。
品类专属红线在包里，更细的口径见 `references/constraints.md`。

## 校验器只查 4 条

段数 ≤ 15 · `hook` 有且仅有段 1 · AI 镜头 ≤ 2 · 禁词命中。
其余（举证配额、角色轮换、语速、两段式、双人参考位）都是**写作时的常识提醒**，
不进机器检查——文案创作不靠校验器出好稿。

## 提示词体检（出片前唯一的门）

```bash
python3 scripts/prompt_lint.py --json {id}.json --duration 15 --reverse-word 还真香
python3 scripts/prompt_lint.py --prompt-file p.txt --strict      # WARN 也算不过
```

**为什么必须有**：写提示词的人不承担出片成本，承担成本的人没机会改提示词。
历史上三次返工（台词念不完、反转没落到最后一拍、情绪平淡）全是提示词层面的问题，
每一次都是 3 元（15s 实测价）。这三类错误都能在提交前用规则拦下来。

三级输出：

| 级 | 含义 | 例子 |
|---|---|---|
| **E** | 硬错误，改完才许提交（退出码 1） | 台词总量 < 60 字、花括号不配对、最后一拍没有反转词、台词里混进时间码 |
| **W** | 会掉分，值得改 | 镜首单字语气词（前粘）、某拍没有身体动作、抽象情绪词多于外化指令、没写"不要第三人" |
| **I** | 只报数字，不下结论 | 某拍台词 8 字偏短、抽象 3 处 / 外化 18 处 |

**几处有意不算错**（别把误报当毛病改）：
- 单拍 6–9 字是允许的——反转句、赌气句本来就短，v8 结尾"嗯…别说…还真香"只有 6 字，效果最好。
- 时间码是**分镜标注**，不是错误；只查台词里混进去的时间码。
- 没有运镜词不算错——固定机位 + 人物动作比乱运镜稳。

**门槛别乱调**：`--min-chars 60` 来自实测（45 字只念到 65% 就停），要降先想清楚为什么。

## 别做

不问预算、不算抽卡系数、不写成本推演（那是生成环节下游的事）；
不把方法论 / 准则全文抄进产物；产物体积要配得上这条视频本身的分量；
不在提示词体检有 E 的情况下把片子交给出片环节；
**不整段沿用上一条的后半段**（只换钩子、后面照抄＝两条片子从第 16 秒起是同一条）；
不在事实层上「换说法」——数值、配料、规格、产地、价格只许照抄，可变的只有顺序与证法；
**不编用量/持久度数字**（2026-11-06 张老师定）：「一罐能吃一个月」这类可被观众验证的说法，
与价格数字同待遇——实测（真开一罐记录吃到第几天，实测本身还能变成素材）、模糊化
（「能吃不少顿」）或进 `pending` 占位，三选一，不许顺嘴写（T2_006 实翻车：AI 念出去无法撤回）。
