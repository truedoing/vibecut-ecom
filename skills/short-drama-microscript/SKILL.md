> **本技能不是入口。** 调度、门禁、状态台账走 `short-drama-supervisor`。

# 短剧微剧本 · 跟人聊出一个完整故事

**这一环写的是「讲什么」，不是「怎么剪」。**

产出是一份 **`微剧本.md`**——立项前先给人看懂的完整故事说明书。它回答三件事：
这条片子讲谁跟谁较劲、每一场用的是原片哪集哪秒哪句台词（**谁说的**）、这场在故事里干什么活。
它不是解说词、不是剪辑清单，是编排环节（`short-drama-script`）的**上游输入**。

> **为什么单独拆出来（2026-11-23 张老师定）**：以前写故事和排镜头挤在编排一个技能里，
> 结果故事还没想清楚就急着排段——D8、D9 就是这么废的：分不清谁在说话，选题只能在「结婚」
> 那一幕打转。现在说话人逐句标好了（全 60 集 1289 句，主角准确率 86.6%），地基有了，
> 才敢把「先把故事聊透」独立成一道。微剧本是**跟人一轮一轮聊出来的，不是一键吐一份**。

## 何时使用 / 不要使用

- **使用**：剧集包、台词库齐了，要在排镜头之前先把"讲什么故事"定下来；或者对已有微剧本
  不满意、要换角度重写。
- **不使用**：排镜头 / 选段 / 五幕 / 写 `plan.json`（那是 `short-drama-script`）；
  装配成片（`short-drama-trailer`）；建包建索引（`short-drama-pack` / `short-drama-asset-index`）。
- 用户说「出个剪辑文案 / 排个段表」指的是编排，不是本技能；说「这故事讲什么 / 写个微剧本 /
  换条线重写故事」才是本技能。分不清就先问一句，别猜。

## 输入 / 输出

| 项 | 说明 |
|---|---|
| 剧集包 | `packs/short-drama/<剧名>/drama-pack.json`（人物表、story_arc、结局门禁） |
| 台词库 | `assets/short-drama/<剧名>/lines/lines_epNN.json` |
| **说话人表（关键新输入）** | `tools/face_label/说话人表_修正后.csv` 或交付包里的同名表：`最终判断` 列是每句台词归给谁。**写微剧本必须按这一列认人，不许再按画面主体猜** |
| 冲突地图（可选，省时间） | 用 `short-drama-script/scripts/storymap.py` 生成；或本技能的 `scripts/who_said.py` 按人查台词 |
| **输出⓪（先给人圈）** | `runs/<剧名>/<任务>/选题单.md`：2–3 条故事线，每条一句角度／主线还是副线／打算多长／推荐哪条为什么；外加推荐哪种 AI 玩法。**人一次圈定，之前不展开故事** |
| **输出①（聊出来、人过目）** | `runs/<剧名>/<任务>/微剧本.md`：一句话故事＋套路骨架＋逐场微剧本（每场注明集.秒、台词、说话人、这场干什么）。**人点头定稿，才交给编排** |

> **文件名口径**：沿用 `选题单.md`（存量台账 `topic` 字段的名字不动，避免断链）；
> 新增 `微剧本.md`。台账在 `artifacts.script.microscript` 记微剧本的身份与过目结论，
> **仍是 `script` 环节内部的前半段，不是第七、第八个流水线环节**。
> 这就是说：环节数不变、11-10 已验收的"五必选环节／无卡点／上游改版连锁重做"不重验。

## 核心原则：微剧本是聊出来的，不是一口气生成的

**这是本技能跟其他技能最大的不同。** 其他环节（抽帧、装配、校验）机器一口气干完交人；
微剧本的价值恰恰在**人跟机器来回聊**——因为"讲什么故事"是判断，不是计算。
一口气吐一份完整剧本，人只能被动接受或整份推翻；分轮聊，人每一步都在做自己擅长的判断。

**先有完整故事，再有剧本（2026-11-23 张老师定）。** 逐场之前必须先写一段
**脱离原剧也能读懂的完整故事**——像小说那样，谁、遭遇什么、怎么翻的身、最后一记停在哪，
外人光看这一段就知道在讲什么、且觉得吸引人。故事不成立，拆再细的场也白搭。
**顺序是：先读故事 → 人认可故事 → 才拆成剧本。** 不许跳过故事直接逐场。

**讲述顺序≠故事顺序（二次叙事）。** 微剧本的场次按**片子怎么讲**排，不按原剧第几集排：
结果前置（最狠的原声开头）→ 背景后补（前史压成十几秒）→ 碎片嵌入（背景里留一句原声刺点）
→ 回到当下冲突（原声对抗）→ 临界画面卡点。详见 `references/二次叙事.md`。
**硬口径：解说词可以自己写，原声台词必须是剧里真有的**——因果能重排，台词一个字不能编。

**默认讲法是解说（2026-11-23 张老师定）。** 张老师的片一直是说书人讲、原剧占大头；
选题单默认推荐解说，纯剪是选项不是默认。

**这份稿子只标故事，不决定制作（2026-11-23 张老师定，分工口径）。**
微剧本只写清每场**在故事里是什么角色**（钩子／背景／对抗／收尾）、原声台词和集秒。
**解说插在哪、写什么词、哪句留给原声、停几秒——全是 `short-drama-script`（编排／导演）的活**，
别在微剧本里写"这段别插解说""卡点配一句旁白"这类制作指令。
判断口诀：**改了它故事变没变？变了归微剧本，没变只是片子好不好看变了归编排。**
收尾尤其注意：用原剧最狠的一句原声收住，不配解说——解说一加上去，原声的余味就说破了。

**三轮对话，每轮都必须停。** 不许跳轮、不许替人把下一轮也做了：

```
第 1 轮  看剧 → 出选题单（2–3 条线） → 停，人圈一条线＋圈讲法
第 2 轮  围着圈定的线 → 聊故事骨架（谁跟谁较劲／信息差／套路） → 停，人改骨架
第 3 轮  骨架定了 → 先写完整故事给人读 → 人认可 → 再按二次叙事逐场展开 → 停，人逐场过 → 定稿
```

**每一轮的规矩**：
1. **先给具体的东西给 humans 看**，再问具体的问题。不问"你觉得怎么样"这种空话——
   给两三个选项、给一段写好的草稿、给一个明确的取舍点，人才判得动。
2. **人说完就落到文件上**，每轮更新一次，别攒到最后。聊完的故事要是只活在对话里，
   下一轮就丢了（前面真发生过：整理半天，用户换窗口，全白费）。
3. **人改哪里改哪里，别整份重写**。第 3 轮人说"第三场台词换一句"，就只改第三场，
   不要借机把全篇顺一遍——那会把人已经认可的地方也改掉。
4. **不确定就摊开说，不编**。台词拿不准谁说的（说话人表里存疑或辅助角色），
   就标"待你听辨"，不许为了剧本好看硬安一个角色。

## 工序

### 第 1 轮：出选题单，人圈线

先全局看一遍剧（不是读剧本，是看冲突地图＋说话人表，省时间）：
- 跑 `short-drama-script/scripts/storymap.py <剧名> --out <任务>/冲突地图.md` 看每集谁在争、最狠哪句；
- 跑本技能 `scripts/who_said.py` 按主角查关键台词（谁在哪集受了辱、谁在哪集翻了身）。

出 **`选题单.md`**，每条线写清五件：
1. **讲谁跟谁较劲**（受力结构，白话：这条片子主要看谁跟谁斗）；
2. **从哪个角度切**（同一个故事，站女儿眼睛看和站妈妈眼睛看是两条片子）；
3. **主线还是副线**（有从头到尾因果链、冲突一次比一次强＝主线，能铺满、4–6 分钟；
   只是同一种场面反复＝副线，只留最经典的几场、2–3 分钟收住）；
4. **大概能撑几场**；
5. **推荐哪条、为什么**，外加**推荐用哪种 AI 玩法**（默认纯剪，真有天然切口才推荐点菜，
   照玩法卡里"什么片子适合用"逐条对，命中哪条写进理由；别替人把玩法定死）。

**停**：把选题单给人，一次圈定「讲哪条线＋用哪种玩法」。**人不点头，不进第 2 轮。**
> 这一步以前在编排技能里叫"出选题单"，现在搬到家。它的身份没变——仍是 `script`
> 环节第一道停、不进作废链；只是从今晚起由本技能产出，台账 `topic` 字段照旧记。

### 第 2 轮：聊故事骨架，人定骨架

人圈定线之后，**不要立刻写完整剧本**。先跟人把骨架聊出来——这是最容易出好主意、
也最容易返工的阶段，值得单独停一次。跟人一起定这几样：

1. **一句话故事**：一句话讲完整个故事（D10 的例子：妈装穷去女儿婚礼被羞辱，女儿为认她退婚丢工作，
   妈用自己人脉把女儿送进公司，女儿不靠妈自己把假记录改回来，当年放狠话的人最后亲口念欢迎词）。
   一句话讲不清，说明线选得太散，退回第 1 轮。
2. **观众知道什么 / 角色不知道什么**：这是信息差型故事（打脸型）的命门。
   D10 就是"观众知道妈有底牌、女儿不知道"。没有信息差的片子走另一套骨架（见下）。
3. **套路骨架选哪个**：从 `references/套路骨架.md` 里挑一个（现在写透了**打脸型**，
   弧线型给了骨架）。挑哪个跟人讲明白为什么——是"看坏人嚣张最后打脸"还是"一个人怎么一步步硬起来"。
4. **起承转合哪四件事**：不用五幕术语，就问人"开头拿什么勾住、中间怎么一步步紧、
   最低点在哪个、最后停在哪一记"。这四件事定下来，故事就立住了。

**停**：把骨架写成几行给人看，人认可或改。**骨架没定，不逐场写。**
> 为什么单独停：D10 那次的骨架（打脸型三段式＋"妈是底牌不是救兵"）是张老师拍板的，
> 定完骨架之后逐场写就很顺；反过来 D9 没定骨架就写稿，写到中段才发现"这不是一个完整故事"，作废。

### 第 3 轮：先写完整故事，再按二次叙事逐场展开，人逐场过，定稿

骨架定了，**先写一段完整故事**（不是解说词、不是分场）——脱离原剧、光看这段就懂在讲什么，
像小说一样有人物、有遭遇、有翻身、有落点。**把故事给人读，人认可了，才往下拆场**。
人不认这个故事，回去改故事，别在场上硬凑。

故事认可后，逐场展开。**场次按"片子怎么讲"排，不按原剧第几集排**（二次叙事）：
开头甩最狠的原声钩子 → 一句解说把前史倒补回来 → 前史压成十几秒背景蒙太奇（留一句原声刺点）
→ 回到当下冲突用原声推 → 临界画面卡点切黑。**解说归解说、原声归原声**：解说词是为重排因果新写的，
原声台词必须逐字对上台词库和说话人表，一个字不能编；画面动作台词表证不了，就得看片确认。

**每一场必须写清四件事**（这是微剧本的硬格式，也是它能被编排直接吃的原因）：

| 写什么 | 要求 |
|---|---|
| 画面对应哪集哪秒 | 从台词库/说话人表取真时间点，不编。写法 `ep1，0–12 秒` |
| 台词原文 ＋ **谁说的** | 台词逐字抄原文；说话人按说话人表`最终判断`列。**拿不准标"待听辨"，不硬安** |
| 这场在故事里干什么活 | 一句白话，比如"第一秒把底牌摊给观众""这句是后面所有事的引信" |
| 给谁留着的钩子 | 这场留了什么疑问往下带；没有就写"无" |

写完 **`微剧本.md`**（模板见 `references/微剧本模板.md`），**逐场给人过**：
- 人可以逐场提意见："这场台词换一句""这场砍了""这里加一场"。
- 按意见改，改完再给人看改过的那几场，直到人明确说"定了"。
- **人点头之前，状态停在 `done`；点头了才升 `approved`**，交给编排。

> 全部台词都要过「谁说的」这一关。以前三法同源（句级表／镜头打标／转写都靠画面主体猜），
> 一致地一起错；现在说话人表按声纹＋人脸定稿，主角 86.6%，比从前可靠，
> 但**辅助角色（周叔、房东、方主管、苏秘书…）不在候选里**，这些台词谁说的仍要人听辨。
> 写进微剧本的每一句关键台词，都要能对上说话人表；对不上的，摊开标出来。

## 跟编排的交接（微剧本 → 分镜清单）

微剧本定稿后，`short-drama-script` 吃它排镜头：**微剧本里每一场的"哪集哪秒"就是选段的锚点**，
"这场干什么活"就是那段的 `beats` 注释，"谁说的"决定解说稿能不能引用这句原声。

- 微剧本 approved → 编排按它排清单，**不改故事，只决定放哪段、什么顺序**。
- 微剧本改了 → 编排的清单重排（等于新一条片子的故事底变了）；这条在主管的改动影响表里登记。
- 编排阶段想改故事（换台词、换顺序、加砍场）→ **退回到本技能改微剧本**，不在清单上偷偷改。
  这是两条技能的分工线，别越。

## 套路骨架（详见 references/套路骨架.md）

**打脸型**（D10 验证过）：靠信息差吃饭，不靠惨。三段——
① 埋雷：观众知道底牌，角色不知道；② 受辱：坏人嚣张拍足，观众憋着；
③ 打脸：反转**由主角自己完成**，底牌人物只能在场不能出手。
一句话：**底牌不是救兵，他铺路，主角自己走最后一步**。爽点靠递过来就废了。

**弧线型**：靠一个人怎么一步步硬起来吃饭，骨架给了但**没有打脸型那样完整验证过**，
用之前跟人说清"这套没打脸型验得透"。

> 骨架是"这类片子以后都这么排"的套路，不是死模板。故事该什么样还看剧本身，
> 骨架只是帮你判断"这个转折该不该在这"。

## 硬判据（人过目时看这几条）

| 判据 | 为什么 |
|---|---|
| 一句话故事讲不清 | 线太散，退回第 1 轮换线 |
| 每场没有"哪集哪秒＋谁说的＋这场干什么" | 编排没法直接吃，等于白写 |
| 关键台词对不上说话人表又没标"待听辨" | 又在按画面猜人，D8/D9 的老毛病 |
| 骨架没跟人定就逐场写 | D9 中段才发现不成立，整份作废 |
| 一口气吐完整份给人，没分轮 | 人只能整份接受或整份推翻，违背"聊出来" |
| 没写完整故事就直接逐场 | 脱离原剧看不懂，D8/D9 的老毛病 |
| 原声台词是编的、画面动作没看片就写 | 违反"台词逐字抄、说话人按表"的铁律 |
| 人改一处，整份重写 | 把人已认可的地方也改了 |
| 微剧本没定稿就排镜头 | 故事没立住就排段，D8/D9 的老路 |

## 交人前自审（自己问，不替代人过目）

1. 每一场的说话人，是从说话人表`最终判断`列抄的，还是又按画面猜的？
2. 一句话故事、观众/角色信息差、套路骨架、起承转合四件事，跟人聊过了吗？还是我自己定的？
3. 有没有一口气把三轮都做完了？该停的地方停了吗？
4. 人上轮改过的地方，我这轮有没有保留、只改他说的部分？
5. `微剧本.md` 落盘了吗？台账 `artifacts.script.microscript` 记了吗？
   人没说"定稿"，state 是不是还在 `done` 没乱升？

## 改动影响（交给主管登记）

| 上游变了 | 本技能 | 下游 |
|---|---|---|
| 说话人表改版（重判了谁说的） | 复核微剧本里每句台词归属，错的重标 | 用到那句的微剧本＋清单＋解说稿 |
