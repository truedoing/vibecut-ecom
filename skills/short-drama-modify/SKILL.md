> **本技能不是入口。** 调度、门禁、状态台账走 `short-drama-supervisor`。
> 本技能**只做「准备」**：算在画上写什么字、第几秒写、怎么动。
> **挂上去是装配器的事**——字幕段写进画面参数表的 `decorate`，装配器组滤镜图时挂 `ass=`。
>
> **为什么不自己出成片**：同去重，对已拼好的 mp4 再压一遍会掉画质。交给装配器一次编码。

# 文字修饰

> **性质**：独立技能目录，**不占流水线工位**。不新增环节、不进环节表、不动门禁、
> 不给存量片子加重做标记。跟去重技能并列，各管一半：去重管画面，修饰管文字。
>
> **硬规矩（2026-11-14）**：加字幕之后叙事质量不许下降。
> 落到工程上是三件事：① 只往画面上叠加，不碰清单任何字段；
> ② **不为凑一句漂亮字幕去多选一段戏**；③ 文字总时长不超过成片 15%。

## 何时使用 / 不要使用

- 使用：清单已定、准备装配，想给片子加标题感（金句上屏、开场悬念、人物名、片尾一句话）。
- 不要使用：选段与五幕重排（`short-drama-script`）、画中画与扫光（`short-drama-dedup`）、
  装配（`short-drama-trailer`）。
- 纯剪片子里**没有强制**：不写 `decorate`，装配器行为跟以前一模一样。

## 管什么 / 不管什么

| 管（只往画上加字） | 不管 |
|---|---|
| 开场悬念句：逐字弹跳，最后三字放大变金 | 段序、段长、选段、五幕、原片台词——**一个字都不改** |
| 人物名标签：两三个名字依次滑入 | 音频。**一律不做**（零解说纯剪靠原片台词讲故事） |
| 金句上屏：从剧集包金句库自动对齐到已选段 | 画中画、扫光、裁切暗角（去重技能） |
| 收尾句：打字机逐字出 | 原剧硬字幕的重铺或翻译 |
| 左上角剧名角标 + 底部五段刻度条（纯图形，不带结构词） | 自己拼成片、二次编码 |
| 一份装配器能直接读的 ASS + 点睛句表 | 片头片尾整段重做（不是「文字」，是剪辑） |

## 输入 / 输出

| 项 | 说明 |
|---|---|
| 输入① 剪辑清单 | `runs/<剧>/<任务>/plan.json`（或 `plan.silence.json`；也可 `--plan` 直指） |
| 输入② 剧集包 | `packs/short-drama/<剧>/drama-pack.json`：金句库、开场句、人物名、收尾句、剧名 |
| 输入③ 字体 | **共用层** `assets/fonts/`（四款中文字体，41MB，一部机器放一次、所有剧共用） |
| 输出① `点睛句表.json` | 哪条金句命中、上屏在第几秒、没上屏的逐条写原因。**给人复核用，装配器不读** |
| 输出② `全片文字.ass` | 装配器要的那份字幕 |
| 输出③ `decorate.json` | 装配器要的四个字段：`ass` / `fontsdir` / `table` + 说明 |
| 装配器接口 | `--dedup <画面参数表>` 里的 `decorate` 段；用 `--into` 自动写进去 |

默认输出到 `runs/<剧>/<任务>/build/修饰/`。

## 用法

```bash
# 只算不写，先看挑了几句
python3 make_ass.py --drama 以真心守护至亲 --task D3_线一认不认这个妈 --dry

# 正式出字幕
python3 make_ass.py --drama 以真心守护至亲 --task D3_线一认不认这个妈

# 出完顺手写进去重技能那份参数表（一条命令接上，不用手工并 decorate）
python3 make_ass.py --drama X --task Y --into runs/X/Y/build/去重/dedup_spec.json

# 抽帧看效果：每处文字一张，几十秒出结果，不用装整片
python3 preview_text.py --drama X --task Y

# 只调某一处
python3 make_ass.py --drama X --task Y --at-from-end 8      # 收尾句提前到末尾前 8 秒
python3 make_ass.py --drama X --task Y --names-at 12        # 人名挪到第 12 秒
python3 make_ass.py --drama X --task Y --names 2            # 只上两个人名
python3 make_ass.py --drama X --task Y --drop gq_003,gq_007 # 某几条金句不上屏
python3 make_ass.py --drama X --task Y --no 人名,刻度        # 关掉某几组
python3 make_ass.py --drama X --task Y --acts "1-4,5-8,9-12,13-18,19-23"  # 五幕边界
```

## 金句怎么落到画面上（这一步是核心）

**靠「集号 + 原剧时间点」自动对齐，不靠人工挑句子。**

1. 从剧集包 `elements.golden_quotes` 取每条金句的 `ep` 和 `t`（原剧第几集第几秒）。
2. 在清单里找「同一集、且这个时间点落在某段的 a–b 之间」的那一段。
   **落不到就落不到**，表里写「这条故事线没选到该时间点所在的段」，不硬塞。
3. 命中后换算成成片时间：`段开始 + （原剧秒 − 段入点）`。
4. 上屏时刻贴着台词那一刻，但保证 3.2 秒动效完整落在这段里，不跨段。
5. 两条筛选：**同一段只留一句**；**与上一条已上屏的间隔小于 2.5 秒不上**。

第 5 条不是拍脑袋：11-14 定版手工删过一条（gq_003，与上一条只隔 2.16 秒，同属开场第一拍），
理由写的是「叠字会糊成一片」。**这里把它变成可重复的判据**——同一份清单跑出来，
自动删的就是那一条，理由还是同一个。已实测：用 `plan.silence.json` 跑，产出的 ASS
与 11-14 定版 **一字不差**（37 条事件全对）。

## 五段刻度条：幕边界从哪来

底部五格是**纯图形**，不带「第一幕」「高潮」这种字。高亮到第几格要知道五幕怎么分。

取值顺序（脚本按这个来，命中哪个会打进产物）：

1. `--acts "1-4,5-8,..."` 命令行
2. 清单里的 `acts` 字段（**推荐**：五幕是剪辑时定的，本来就该记在清单里）
3. 配置文件里的「幕边界」
4. 按段数等分五组（兜底，会打印提示）

**清单现在普遍没有 `acts` 字段**，所以多数时候走第 4 条兜底。等分跟人工排的五幕会有出入
（23 段等分是 1-5 / 6-10 / 11-15 / 16-20 / 21-23，定版人工是 1-4 / 5-8 / 9-12 / 13-18 / 19-23），
只是刻度条切换点早晚几秒，不影响叙事。要精确就补 `acts` 或加 `--acts`。

## 字体：41MB 不进包

四款字都是开源可商用的（思源黑体 / 思源宋体 SIL OFL，OPPO Sans 免费商用）：

| 用途 | 文件 | 家族名 |
|---|---|---|
| 开场悬念句 | SourceHanSansSC-Heavy.otf | Source Han Sans SC Heavy |
| 角标 / 人名 | OPPOSans-H.ttf | OPPO Sans H |
| 金句 | SourceHanSerifCN-Regular.ttf | Source Han Serif CN |
| 收尾句 | SourceHanSansCN-Bold.otf | Source Han Sans CN Bold |

放共用层 `assets/fonts/`，一部机器放一次、所有剧共用。**不进专家包**——41MB 会让
0.7MB 的包翻六十倍（11-16 刚为这个把 ffmpeg 从包里拿出去）。

**缺了就降级**：用这台机器自带的中文字体（Mac PingFang/宋体、Windows 微软雅黑/宋体），
能出片，但**字号粗细跟定版不一样**，脚本会在报告头三行明说，`decorate.json` 里也标着
「系统字体降级」。别拿降级版当定版效果交付。

## 验收（三步，缺一步都不算验过）

1. **`--dry` 看清单**：几处文字、分别在第几秒、哪条金句没上屏、为什么。
2. **抽帧看画**：`preview_text.py` 出 9 张图（开场、每条金句、人名、收尾），
   看三件事——**字有没有压脸、长句有没有被切、字号够不够**。
3. **装成片再抽一次**：整片装配后必须重抽，因为画中画会改变人物在画面里的位置，
   单帧预览看不到那一层。

## 已知带伤与边界

- **人名会压脸**：定版人名在 `y=350`（540 基准），落在人物额头一带。11-16 抽帧实测，
  新娘那一场「林秀兰 许宁 许晴」正好压在人脸上。这是**定版样式本身**的问题，不是脚本错。
  要改就调配置 `人物名标签.names.y`（往下挪）或 `at`（换时刻）。**还没定案。**
- **五幕边界靠等分兜底**：清单没写 `acts` 时只能等分，跟人工排的幕有出入（见上）。
- **降级字体不是定版效果**：字体包不在的机器上出的片，字重和字宽都不一样。
- **文字不解析句意**：金句是「原剧里最狠的一句」，从哪条线里挑哪几句仍然是人定的。
  本技能只保证「挑了的那几条在画面上排得住」，不保证「挑得对」。
- **平台读数没有数字**：加字幕能提升多少完播/点击，**没有测过**，不给效果承诺。
