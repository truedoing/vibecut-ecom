# ecommerce-mix

description: "AI 钩子过审之后做混剪：算旁白句边界、生成段清单骨架、用官方素材拼成整片。核心是段切换点对齐旁白句边界，音画同步和节奏一次达成。触发词：混剪、合成、拼片、句边界、段清单。"

## 这个技能只做后期装配

**前置硬规则：AI 钩子必须已经过人工审核**（五官/第三人/虚焦/台词/切点）。没过审不进这里。

理由三条，都吃过亏：钩子一条约 10 元、混剪本地零成本，顺序反了混剪白做；旁白是按钩子**实际时长**配的，钩子重出旁白也得重配；钩子的错（吞字、撞脸、切点漂移、标签露字）只有人眼看得见，脚本检不出。

分工：`ecommerce-video-gen` 负责出片（Stage A，花钱），本技能负责装配（Stage B，免费），`ecommerce-narration` 负责旁白。

## 三步

```bash
# ① 旁白（在 ecommerce-narration 技能里出，不在这里）
python3 skills/ecommerce-narration/scripts/narration.py \
  --card <角色卡>/card.json --script-json <文案>.json \
  --target-rate 4.86 -o vo/女主解说_正式版.mp3

# ② 句边界 + 段清单骨架
python3 skills/ecommerce-mix/scripts/align_bounds.py \
  --vo vo/女主解说_正式版.mp3 --script-json <文案>.json \
  --json-out bounds.json --segs-out segs.json \
  --shots "C5319+DJI_0397,C5388,C0420+C5315,C5306+C0449,C1301,C5384,C5396,C5315@3.7+C5319@5,C5394"

# ③ 填 src / pre 后合成
python3 skills/ecommerce-mix/scripts/mix_final.py \
  --hook AI1.mp4 --segments segs.json --vo vo/女主解说_正式版.mp3 \
  --vo-gain 1.41 -o final.mp4
```

`--shots` 语法：逗号分句，一句内多个镜头用 `+` 连；`C5319@5.0` 表示同一素材第二次使用从第 5 秒起（避免两处用同一个开头，观众看得出重复）。

## 核心设计：段切换点 = 旁白句边界

每句说完立刻切画面。这一条同时解决两个问题——音画对位，和节奏紧凑（不用另配 BGM 卡点）。

段长**不是拍脑袋**：旁白先跑 `silencedetect` 找停顿，再按文本对应出句边界。

**边界算法：比例预排 + 吸附静音中点。不要手搓 DP。**
候选静音点里混着字与字之间的小停顿，DP 的平方代价除以句长后对长句几乎不罚，会把 23 字的句子压到 0.149 s/字（真实全局 0.205），前面几句变得赶、后面变慢。吸附法把误差锁在 ±0.3 秒内，观众无感。

## 素材处理链

官方素材 1920x1080 横版 → 与 AI 钩子同参：

```
crop=608:1080  →  scale=720:1280,fps=24
```

钩子即使是 480p 也走同一条链，两边都放大到 720x1280，接缝看不出来。

## 账要平（脚本会硬拦）

**混剪总长必须 ≥ 旁白文件时长。** 旁白头尾的静音常让文件比内容长 0.3–0.6 秒，末段要留够余量，别卡在等号上——浮点比较 36.839 vs 36.84 也会被拦。

- 旁白 gain 1.41（+3dB）对齐钩子响度；`adelay` 到钩子尾；片尾 video fade 0.6s + audio fade 1s。
- 段内多镜头按执行单比例分（如句1 的 5.2s = 舀酱 2.3 + 航拍 2.9）。

## 脚本

| 脚本 | 作用 |
|---|---|
| `align_bounds.py` | 旁白句边界对齐（比例预排+吸附静音），可直出段清单骨架 |
| `mix_final.py` | 裁切→拼接→混音→成片，内含总长校验 |

## 留意点

- 素材偏暗是原样（如 C0449 手摊颗粒），别在混剪里强行提亮，会与其他镜头色温断裂。
- 厂商素材里出镜的紫色美甲、桌面杂物属原始画面，要换就换素材，不要靠裁切规避。
- 段清单只填 `vid/src/dur/pre` 四个字段，多填的字段会被忽略——结构改动只改脚本，别改 JSON 约定。

## 别做

不在这个技能里出片、不重配旁白、不改文案（那是前面技能的事）。
钩子没过审不做混剪。
