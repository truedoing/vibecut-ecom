# 打标字段规范（VLM 输出契约）

每帧输出一个 JSON 对象，数组顺序与传入图片顺序一致：

```json
{
  "i": 1,
  "desc": "一句话画面描述（20-40字，具体到物体和动作，不评价不发挥）",
  "subject": "画面主体（如：虎坚果酱罐体 / 油莎豆颗粒 / 灌装线 / 沙漠绿洲）",
  "shot_size": "特写|近景|中景|全景|航拍",
  "scene": "场景（如：室内桌拍 / 车间 / 田间 / 沙漠）",
  "text": "画面中可读的文字，没有则为空字符串",
  "usage": ["product", "texture"]
}
```

## usage 枚举（只允许 6 个值）

| 标签 | 含义 | 典型画面 |
|---|---|---|
| product | 罐体/包装/品牌 | 罐体摆拍、标签特写、堆头 |
| process | 工艺过程 | 磨酱出料、灌装线、低温烘焙 |
| origin | 种植/产地 | 田间、机械作业、沙漠绿洲、航拍 |
| texture | 质地/细节 | 酱体拉丝、涂抹、颗粒特写 |
| hand | 手部动作 | 开罐、舀取、涂抹、握持 |
| other | 以上都不是 | 空镜、天空、设备局部 |

## 提示词红线

- 只描述画面里**确实可见**的东西；认不出就写"未识别物体"，禁止编造品牌、人物身份。
- `text` 只抄画面里清晰可读的字，模糊就留空。
- `desc` 用名词短语+动词的客观句式，禁止"美味""诱人"等主观词。
