> **本技能不是入口。** 调度、门禁、状态台账走 `short-drama-supervisor`。
> 本技能只负责「放哪几段、按什么顺序、为什么」，不负责把画面拼起来。

# 纯剪预告 · 编排

**这一环写的是「怎么剪」，不是给人念的词。** 纯剪预告零解说、零口播、原片原声混剪，
所以产出的是一张剪辑清单（`plan.json`：挑哪几场、什么顺序、每场为什么放），不是一段旁白或解说稿。

> **用户说「出个剪辑文案」时，指的是这份剪辑方案**，不是解说词。别因为带个「文案」二字
> 就去写口播稿——那是已退役的电视框三拍形态。收到这类话，先把方向卡给人选线。

> **形态边界（2026-11-10 张老师定）**：sd_001 电视框三拍线已退役——那份执行单里的
> 「165 字解说词 + 14 段时间轴 + 王婶出镜几段」是旧形态，别照着写。
> 方法论全文：`docs/纯剪预告方法论_v0.1.md`（正文已升 v0.2）。

## 何时使用 / 不要使用

- 使用：剧集包、台词库齐了，要出一条纯剪预告，或换受力结构出第二条片子。
- 不使用：建包（`short-drama-pack`）、建索引（`short-drama-asset-index`）、
  按玩法生成素材段（`short-drama-video`）、装配成片（`short-drama-trailer`）、
  带货口播脚本（`ecommerce-script-gen`）。

## 输入 / 输出

| 项 | 说明 |
|---|---|
| 剧集包 | `packs/short-drama/<剧名>/drama-pack.json`（`story_arc` + finale 门禁） |
| 台词库 | `assets/short-drama/<剧名>/lines/lines_epNN.json` |
| 素材索引 | `assets/short-drama/<剧名>/asset_index.json`（已建时作辅助，不替代台词库核秒） |
| 玩法菜单 | `runs/工作台.json` → `shared.ai_strategies`（有哪些玩法可选、各是什么状态） |
| **输出⓪（先给你过目）** | `runs/<剧名>/<任务>/方向卡.md`：**2–3 条故事线**，每条一句角度、能撑几段、推荐哪条和理由；**外加推荐用哪种 AI 玩法、为什么**（不点菜＝纯剪）。**你一次圈定，之前不排清单。** |
| **输出①（机读真源）** | `runs/<剧名>/<任务>/plan.json`，字段格式见 `short-drama-trailer/scripts/mix_trailer.py` 头部注释 |
| **输出②（人审版）** | `runs/<剧名>/<任务>/选段说明.md`：五幕归属、But/Therefore 连接、砍场前因复述 |

> **文件名口径（11-10 统一）**：规范名 `plan.json`；同一任务多版时允许 `plan_<tag>.json`
> （存量 `plan_v3ws.json` 即此）。台账 `artifacts.script.path` 一律写实际文件名，不写占位符。

> **点没点玩法不写进 `plan.json` 的额外字段**：只体现在清单里有没有留插入位，
> 免得装配器吃到不认识的字段。选择本身记两处：方向卡里给人看，
> 状态台账顶层 `ai_strategy` 给主管算影响范围（不写＝`none`＝纯剪）。

**验收口径**：`plan.json` 必须能被 `short-drama-trailer` 直接 `--plan` 装配，不需要翻译、不需要补字段。
这是「这一环的产物能不能被下一环直接吃」的唯一硬判据。

## 工序（六步，第 1 步完必须停）

1. **出方向卡，先停**：全局把整部剧看一遍，列出 2–3 条能单独撑起一条片子的故事线。
   每条写清四件：**讲谁跟谁较劲 / 从哪个角度切 / 大概能撑几段 / 推荐哪条、为什么**。
   例子（八零憨妻）：婆婆线（外人施压、丈夫护不护）／标签线（"憨媳妇"这顶帽子怎么扣上又摘掉）／
   发家线（穷→挣钱，冲突太散，不推荐）。
   **第五件：推荐用哪种 AI 玩法、为什么**。读工作台的玩法菜单，从已做出来的里面挑；
   默认纯剪，只有这部剧真有天然切口才推荐点菜。写清点了玩法会多出什么（插入位、一次出片费用、
   台词人审），**别替人把玩法定死**。
   **把方向卡交给人，一次圈定「讲哪条线 + 用哪种玩法」才往下。人不点头，不排清单**——
   选段一开工就是十几段的沉没成本，方向错了整张表白排；而点了玩法清单就得留插入位，
   清单排完再点，整张表要推倒重排。方向卡与 `plan.json` 一一对应，换了线就是新一版方案。
   > 这一步补的是 11-10 查出的空档：以前"抽哪条受力结构"是在对话里定的，没落盘、没让人点头，
   > 一口气就排到 15 段。方法论文档「从 20 集里抽出一条受力结构重新讲一遍」里那个"一条"，现在有主了。
   > 20:4x 又补一层：**王婶只是 AI 玩法菜单里现在唯一做出来的一种，不是固定环节**；
   > 菜单以后会加菜，所以选玩法和选线一起圈，但位置留在菜单里，不建空技能。
2. **定轴**：在**选定的那条线里**扫「外人施压 / 自家人挡」结构。重复型（段 = 完整小冲突 15–25s）/
   弧线型（段 = 态度刻度 5–15s + 回撤段）。**高光集锦禁止**——实测等于播原片。
3. **选段三道判据**：① 对轴；② 脱离前后集能否看懂（赵四上门这种要背景的不用）；
   ③ **三拍完整单元**：挑起→交锋→落点，缺一拍宁可整场拿进来。金句抽取 ≠ 场景。
4. **五幕重排**：Tease（最强台词前置）→ Establish（三拍拒绝 Rule of Three）→
   Escalate（反击 + 回撤 false victory）→ Brake（黑场急停 + 最静一句）→ Button（当众认 + 字幕卡）。
   段间过 **But/Therefore 连接律**，写出「然后…然后」就重排。前 45 秒每段必须是一次拒绝或反击。
   **若方向卡点了玩法**：在第一场后留黑场插入位，并把该处上下文写清，供下一环按它写素材台词。
5. **写 plan.json**：每段 `beats` 写「挑起…交锋…落点」；黑场 `d`、字幕卡 `card` 按装配器格式。
   `src_dir` 用相对路径或环境变量，别写本机绝对路径。
6. **时长账与砍场**：诚实口径 4–6 分钟（占原片 40–50%）。压时长刀序：先砍功能重复场 →
   再砍标签来源场（须张老师拍板）。**每砍一刀，在 `选段说明.md` 复述砍掉的是什么前因。**

## 硬判据（人审只看这几条）

| 判据 | 出处 |
|---|---|
| 没看过原剧的人，不靠解释能否看懂这场戏在争什么 | 三次失败同根源：sd_003 时序跨度 / v1 冲突密度 / v2 金句切碎 |
| 覆盖大结局的幕必须带 `restricted`，素材禁入成片 | `short-drama-pack` 铁律 + 校验器 ERROR |
| 切台词边界用原片硬字幕出现/消失（±0.3s） | 田间底噪 -22dB，silencedetect 测不出人声 |
| 出点别贴 format 时长，留 0.1s 余量 | 每集视频流比音频短 0.6–0.7s，超限装配器拒装 |
| 回撤段（刚护完就派活）不能省 | 弧线型张力的续命器 |
| 方向卡没圈线、没点玩法，不许排清单 | 11-10 两道空档都是「替用户决定了」 |

## 改动影响（交给主管登记，改前先查这张表）

| 上游变了 | 本技能 | 下游要重验 |
|---|---|---|
| **换了一条故事线 / 方向卡改了** | **整张清单重排，不是改几段** | 全部 plan 与成片（等于新一条片子） |
| **换了一种 AI 玩法 / 从纯剪改成点菜** | **整张清单重排**（留不留插入位） | 该条片子的成片；剧包不动 |
| 剧集包 / 台词库 | 复核方向卡还成不成立，再重跑选段 | 本剧全部 plan 与成片；别部剧不受影响 |
| 素材索引 | 复核三拍判据 | 用到该集的 plan |
| 某道玩法配方微调 | 本技能不动；素材段要重做 | 点了这道玩法的片子；纯剪不受影响 |
| 五幕 / 三拍方法论 | 重排全部段表 | 定版用例（sd_005 v3 = 325.1s） |
| 本技能改了清单 | — | 成片重装配 + 时长回归；**已生成的素材段可复用，别重跑花钱那步** |

## 自检五问

1. **方向卡落盘了吗？人圈定的是哪条线、哪种玩法，`plan.json` 是不是只讲这一条？**
2. `plan.json` 能直接 `--plan --dry` 跑通吗？有没有塞装配器不认的字段？
3. 每段 `beats` 三拍全不全？前 45 秒有没有温情段混进来？
4. 砍掉的场，前因复述写进 `选段说明.md` 了吗？
5. 点了玩法的话，插入位留了吗、那处上下文够下一环写台词吗？没点就别留空位。
