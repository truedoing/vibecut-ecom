# 清单人审表（模板）

> 一条片子一份，和剪辑清单放同一个目录，文件名 `清单人审表.md`。
> **这份是给人过目用的，不是给机器打勾的。** 六条规矩是判断，不是勾选框。
> 填表人：编排环节。看表人：张老师。**人没点头，不许拼成片。**
>
> 用法：复制本文件到 `runs/<剧名>/<任务>/清单人审表.md`，逐行填实际情况，别只写「通过」。

## 二、六条，一条一行

| 看什么 | 这张清单实际情况 | 过 / 不过 / 说不清 |
|---|---|---|
| 幕齐不齐：**主线**五幕（强台词 → 三拍拒绝 → 反击加回撤 → 急停 → 当众认）；**副线**只取三幕（强台词 → 三拍拒绝 → 当众认／点题），中间那串来回整串砍掉 | | |
| 前 45 秒每段都是一次拒绝或反击，没混进温情段 | | |
| 每场是完整一单元：挑起、交锋、落点（例外见下一节） | | |
| 段与段之间是「但是 / 所以」，不是「然后…然后」 | | |
| 砍掉的场，前因写清了 | | |
| 时长对得上定性：**主线 4–6 分钟 / 副线 2–3 分钟**；「占原片 40–50%」没写分母，只作参考不作合格线 | | |

## 三、三拍那条的例外（别硬套）

下面几类段本来就不写三拍，**不算缺**：

- 回撤段（刚护完就派活）
- 急停黑场
- 当众认 / 收尾 / 字幕卡
- 点了玩法时留的插入位

依据：定版用例 D5 婆婆线 11 个原片段里，8 段带完整三拍，3 段是上述例外
（回撤、当众认、收尾），该片已人审通过。检查口径不能把定版用例判成不合格。

## 四、工程两项（程序会查，人扫一眼即可）

- 试跑通过：清单能直接 `--plan --dry`，没有程序不认的字段。
- 出点别贴视频流尾：差 0.1s 以上；贴边的段列出来，做帧级复核。
