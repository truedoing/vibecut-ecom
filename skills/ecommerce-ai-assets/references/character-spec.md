# 定妆图与音色规格

## 定妆图：单图双联（一张图，两个视图）

**左格 = 3/4 侧身半身像（人物参考），右格 = 同套衣服领口袖口细节（服装参考）**，
中间一条两指宽白色分隔条，像手机相册里拼好的两张照片。

提示词模板（1024x1536 竖版）：

```
一张竖版双联拼图：左右两格并排，像手机相册里把两张照片拼在一起，
两格之间是一条两指宽的白色分隔条，整幅图无文字、无水印、无装饰边框。

左格（约占三分之二宽）：一位{age}岁左右的中国城市{gender}，{occupation}，气质{temperament}。
他/她侧身站在{place}（城市场景），身体是接近正侧面的侧身姿态，肩膀一前一后，
只能看到单侧肩线和背部轮廓；脸朝向画面一侧，接近正侧面角度，能看到单侧的眉骨、
眼睛和鼻梁轮廓，视线望向窗外的光，不看镜头，不是正脸，表情{expression}。
穿{wardrobe}。{grooming}，皮肤有自然纹理{skin_note}。
自然光从画面左侧的落地窗照进来，暖白色，柔和；背景是{bg}，略微虚化。
真实手机后置摄像头随手拍的质感，不是影楼照，不是商业摄影，不是广告大片。

右格（约占三分之一宽）：同一位人物身上{key_garment}的局部特写，
只拍领口、肩线和袖口的位置，能看清{fabric_texture}。这一格里没有人脸，只有衣服局部，
浅色背景虚化。
```

要点：

- **侧身定案（张老师拍板）：接近正侧面、不看镜头**——脸转向镜头的 3/4 侧身会变正脸感。
  提示词必须同时锁三处：身体（接近正侧面/单侧肩线）、脸（接近正侧面/看单侧五官轮廓）、
  视线（望向窗外的光/不看镜头）。少锁一处模型就会转回来看镜头。
- 提示词里别用 markdown 加粗（星号会当字面发过去），要强调就重复关键词。
- **人物消费气质要配产品客单价**：中高客单的产品，人物是都市白领 / 刚退休的城市中产，
  场景用现代住宅 / 城市客厅餐厅，**不要农村院落、不要过度陈旧的家居**。
- 服装**就是片中要穿的**：换装等于换人；右格细节图同时是服化道执行依据。
- 年龄写「42岁左右」这类**具体偏中值**的数字 + 「显年轻」；只写区间容易生成到区间上限。
- 女性加「淡妆、皮肤紧致有光泽」可对冲 AI 图默认的老化倾向，但仍保留「自然纹理不磨皮」压塑料感。
- 描述路径是「手机相册拼图」，**不是** character sheet / 设定稿。

## 反例（触发限制或效果差的写法）

| 别写 | 为什么 |
|---|---|
| 三视图 / character sheet / 设定稿 / turnaround | 像人物设定工作流，容易触发真人内容限制 |
| 超写实 / 8k / 详毛孔 | 撞「深度伪造真人」审核 |
| 年轻化形容词（气质佳/冻龄） | 与目标人群不符，且容易产出网红脸 |
| 右格里出现人脸或第二个人 | 模型可能画成两个人；右格只准有衣服局部 |

## 生成后处理

1. 自检：侧身角度（接近正侧面、不看镜头）、手部无畸形、右格无人脸、年龄观感与卡一致。
2. 裁水印（右下角约 60px）：`ffmpeg -i in.png -vf "crop=iw:ih-60:0:0" -q:v 2 portrait.jpg`
3. AI 图默认显老，观感超过 age_feel 上限就重生成，**不要改卡迁就图**（改卡只准往年轻改）。

## 音色：MiMo TTS（voicedesign 造锚 + voiceclone 固定）

关键认知：**voicedesign 不返回固定 voice_id，每次现造**——直接拿它配音，两条视频音色会漂。
一致性的锚是**样本音频本身**：

```
① 造锚：gen_voice.py --card <card.json>          → voice.mp3（19秒固定文本，人耳审听）
② 配音：gen_voice.py --card <card.json> --clone --text "台词" -o out.mp3
        → voiceclone 传 voice.mp3 做 DataURL，音色与锚一致
```

- `voice.desc` 写全：年龄段 / 音区 / 语速 / 说话劲头（**劲头是灵魂**：「说话直」和「细声细气」是两个角色）。
- `card.json` 里 `sample` 不只是试听，**就是 voiceclone 的输入**，丢了 = 角色嗓子丢了。
- 换锚（重跑 ①）后旧台词要重配，别新旧混用。
- 固定文本约 75 字 ≈ 19 秒，够 voiceclone 用，也方便跨角色横向比较。
- 踩坑：clone 的 `audio.voice` 必须 DataURL（`data:audio/mpeg;base64,...`），裸 base64 报 400。

## 环境卡必填

```json
{"id": "env_001", "name": "城市餐厅晨光", "light": "左侧落地窗自然光，暖白，无顶灯",
 "props": ["浅木色餐边柜", "白瓷杯", "绿植"], "time_feel": "上午", "status": "ready"}
```

`light` 是混剪对齐用的：AI 钩子在这张图的光线下生成，混剪素材也要同色温。
环境风格与角色消费气质一致（城市场景配都市角色）。

## 一致性自检（生成后立刻看）

1. 左右格衣服是不是同一套：颜色、针织纹理、领口内搭
2. 年龄感与角色卡 age_feel 是否一致（图为准，不一致重生成）
3. 手部：手指数量、是否畸形（AI 图最高发的破绽）
4. 有没有水印/文字：右下角裁 60px
