# 定妆图与音色规格

## 提示词模板（生活照路径）

### 主参考 portrait_side.jpg

```
一张普通家庭生活照：{age}岁左右的中国{region}{gender}，{figure}，
穿{wardrobe}，站在{place}里，身体呈四分之三侧身角度，脸朝向镜头方向
{expression}，自然光从{light_side}窗户照进来，背景是略微虚化的{place}细节，
真实手机随手拍的质感，皮肤有自然纹理，不过度锐化，不是影楼照，不是商业摄影
```

要素逐条过：

- 「四分之三侧身」：完全侧脸喂 Seedance 辨认不出人，正面又太像证件照
- 服装**就是片中要穿的**：换装等于换人
- 「皮肤有自然纹理」「不过度锐化」：压住 AI 商业图的塑料感
- 表情给一个词（无奈/不服气/放松），别给一串

### 面部细节 detail_face.jpg（image-to-image）

```
同一个人，正面面部特写，占画面大部分，中性表情微微放松，
自然室内光，保持她的{发型}和面部特征不变，
皮肤自然纹理和皱纹清晰可见，手机前置摄像头拍摄的真实感，背景虚化的{place}
```

**必须**带 image1（主参考）走图生图，凭空生成的第二张是另一个人。

## 反例（触发限制或效果差的写法）

| 别写 | 为什么 |
|---|---|
| 三视图 / character sheet / 设定稿 / turnaroun | 像人物设定工作流，容易触发真人内容限制 |
| 超写实 / 8k / 详毛孔 | 撞「深度伪造真人」审核 |
| 正面 + 纯色背景 + 无表情 | 直接变证件照，也容易被判真人复刻 |
| 年轻化形容词（气质佳/冻龄） | 与目标人群不符，且容易产出网红脸 |

## 音色登记模板

```json
"voice": {
  "platform": "",
  "voice_id": "",
  "desc": "{年龄段}{性别}声，{音区}，语速{快慢}，{口音}，{说话劲头}",
  "sample": ""
}
```

说话劲头是关键：同一张脸配「说话直」和「细声细气」是两个角色。
desc 现在就写全，voice_id 定平台再补——换平台时按 desc 重挑，身份不断。

## 环境卡必填

```json
{"id": "env_001", "name": "家常厨房暖光", "light": "左侧窗自然光，暖白，无顶灯",
 "props": ["砧板", "调料瓶", "围裙挂钩"], "time_feel": "白天", "status": "ready"}
```

`light` 是混剪对齐用的：AI 钩子在这张图的光线下生成，混剪素材也要同色温。

## 一致性自检（生成后立刻看）

1. 两张图是不是同一个人：发型、脸型、痣/斑点、服装
2. 年龄感与角色卡 age_feel 是否一致（图为准，不一致改卡）
3. 手部：手指数量、是否畸形（AI 图最高发的破绽）
4. 有没有水印/文字：有就裁
