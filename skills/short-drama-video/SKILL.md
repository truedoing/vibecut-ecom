## 工序（五步，两道必须停）

1. **写台词**：立场是**看剧者观后感**，起疑不给答案（「图啥呀？」收尾）；只说自己的词，
   不与剧中人同框/对话/用结局。5–6s 说话窗口，语速 ≤4.5 字/s。
   避开易念错词（「不动窝」翻车 →「不肯走」过）。
   → **停 1：台词必须张老师在会话里人审通过，才允许花钱。历史上多次被否。**
2. **备料与提示词**：参考图 ×2（**不带脸锚**）+ 音频锚；骨架＝电视屏播上一场尾画面 →
   镜头后拉显出屋与王婶 → 对镜头说观后感 → 推回屏幕满画幅。
   **「王婶说剧」四字道具写成主体物件**（台历/奖状/年画任选，位置显眼），并单独强调四字内容。
3. → **停 2：先 dry-run 核请求体，结果报出后再提交。**
4. **提交**：本技能 `scripts/seedance.py`（自带，独立维护）；10s / 480p / seed 20261109。
   `--prompt-file` 读长提示词（带台词的提示词走 shell 转义必翻车）、`--dry-run` 只打请求体不提交、
   `--task-id` 断点续查（轮询中断别重出，重出重复计费）。
5. **验收三件**：抽帧联系表（手/衣/色温/无第二人）+ 全尺寸细节帧（屏幕内文字 / 台历四字 / 手指）+ **ASR 逐字比对**台词；
   **再加一件：首帧与末帧单独看**——一镜到底的镜头运动看两头就能判真假。结论写进 `report.json`。

## 硬纪律（全部实测换来）

| 纪律 | 原因 |
|---|---|
| 参考图含真人（**含 AI 生成的脸锚帧**）一律不用 | 400 拒不扣费；无脸场景图 / 服装图可过 |
| 默认 `--resolution 480p` | 5s/1080p=245025 tokens vs 10s/480p=100858；例外须张老师本人就该条明说 + 写台账 |
| 成本口径 10s/480p ≈ **2 元** | 张老师实测；10 元是 15s 带货片老数，别再报 |
| 首尾帧封闭模式不能带参考图/音频 | 「剧画面↔AI 世界」精确衔接实测不通，改 B 案：AI 只做镜头运动 + 后期 0.4s 叠化 |
| AI 写字与 seed 强相关 | 字错先换 seed（「王婶看剧」seed 20261108 写成「三婶」，换 20261109 即对），别死磕提示词 |
| 四字道具写背景细节不会生成 | `wangshen_v1` 台历实测没出来；仍失败按「换 seed → 后期贴图」兜底 |
| **四字道具写成主体物件就出得来** | `wangshen_v2`（seed 20261109）台历竖排「王婶说剧」2–10 秒各帧清晰可读，同时台标也消失——写法改对比换 seed 更省 |
| **「一镜到底」的镜头运动提示词拦不住** | v2 把前后拉镜写到时序上，实际仍是开头已拉开、结尾 6–9 秒广角全景、10 秒直接切中景（等于一次切镜）。判定只认首帧与末帧，不认提示词 |
| 出片人审不过不重交 | 先报偏差与选项，列给张老师定，不自行重出 |
