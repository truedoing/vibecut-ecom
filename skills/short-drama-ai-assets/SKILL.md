# 短剧 AI 资产 · 王婶与场景

> **2026-11-10 独立**：不再共用 `ecommerce-ai-assets`。原因不是命名，
> 是**两类角色的生成规矩正好相反**：电商要含脸定妆照，短剧因为真人审核墙**一律不能用脸锚**。
> 捆在一个技能里，改一边就会把另一边弄坏。

## 输入：根据素材与文案建卡

| 来自 | 取什么 |
|---|---|
| 素材（原片 + 台词库） | 剧里有没有**现成的邻居位**（本剧刘婶爱嚼舌根、借米不还 → 王婶做「另一个邻居」，不用硬造设定）；年代、服装、色温 |
| 文案（plan.json 织入位上下文） | 王婶这一句要对着哪场戏说；说话窗口 5–6s；要区隔的是「剧内」还是「剧外」 |
| 选片结论（存量文件名叫选品决策书） | 风格（轻喜 / 苦情 / 爽剧反杀）——风格判错，王婶口吻全错（本剧曾先判苦情、看到台词后翻案为轻喜反杀） |

**卡不是凭空造人设**，是从素材里找位置、从文案里定用途，再落成可复用的资产。

## 三条身份硬规矩（孪生解说）

1. **不与剧中人同框、不对视、不对话**；王婶是隔壁院的人，不进剧内场景。
2. **只说自己的词**，绝不说剧中台词、不替剧中人解释、不用结局。
3. **跨剧复用**：角色是 IP，不属于任何一部剧。换剧只换她评的那场戏，不换人。

区隔靠两样：**色温差**（剧内 vs 屋内）+ **视觉标记**（下节）。

## 视觉标记：硬要求

**王婶 AI 画面里必须出现带「王婶说剧」四字的道具**——台历 / 墙上奖状 / 年画类，
任选其一，位置显眼固定（柜面 / 墙面）。作用：IP 区隔 + 跨剧可复用的场景标记。

实测教训（`wangshen_v1`）：提示词写「柜面上有一本台历」**没生成出来**。写卡和写提示词时：
- 把道具写成**主体物件**（「柜面正中立着一本红色台历，封面四个大字：王婶说剧」），
  并在文字描述里单独强调四字内容；写成背景细节不生成。
- 字错 → 换 seed（AI 写字与 seed 强相关：seed 20261108 把「王婶看剧」写成「三婶」，20261109 即对）。
- 兜底：后期本地贴图（ffmpeg overlay，免费）。

## 真人审核墙（本技能与电商资产最大的不同）

| 能过 | 不能过 |
|---|---|
| 无脸的**环境图**（屋内老电视、柜面、墙面） | 含真人的参考图，**包括 AI 生成的脸锚帧** |
| **服装图**（玫红碎花盘扣棉袄，无脸） | 定妆照、单图双联人像、portrait.jpg |
| 音频锚 mp3 | — |

含真人一律 400 拒不扣费。所以**本技能不产出定妆照**，只产环境图 + 服装图 + 音频锚。
色温、服装、道具的一致性靠这三样锚住，不靠脸。

```
    wardrobe.jpg     服装图（无脸）
    anchor.mp3       王婶片内音色锚（跨剧不变，丢了=嗓子丢了）
  environments/
    wangshen_room/card.json + ref.jpg   屋内老电视：电视屏 / 柜面 / 四字道具 / 光线与色温

```

> **历史资产不迁移**：`assets/ai_assets/characters/ch_003_王婶`、
> `assets/ai_assets/environments/env_003_王婶屋内老电视` 是 11-09 建在电商库里的存量，
> 现有 `wangshen_v1` 出片链路仍按原路径引用。新资产一律落本目录；
> 引用存量时在 `registry.json` 登记来源，不复制、不搬动。是否整体迁移由张老师定。

## 卡片必填字段

| 卡 | 字段 |
|---|---|
| 角色 | `identity_rules`（三条硬规矩）/ `age` / `wardrobe` / `fixed_prop`（跨剧不变）/ `fixed_opening`（手上有活）/ `voice_style` / `tone`（带笑、护短、有点得意） |
| 场景 | `place` / `light` / `color_temp_gap`（与剧内差多少）/ `props`（含四字道具的**主体物件写法**）/ `screen`（电视屏里播什么） |
| 锚 | `source`（从哪条已过审片子裁的）/ `duration` / `asr_checked`（咬字验收结论） |

**点题词纪律**：台词立场是「看剧者观后感」，**起疑不给答案**；影视解说那套「揭示给答案」不适用短剧。

## 输出与下一环

产出 `card.json` ×2 + 三张锚（服装图 / 环境图 / 音频锚）+ `registry.json`。
清单的**完整路径是 `assets/short-drama/ai_assets/registry.json`**（相对仓库根）——
下游技能与状态台账一律写这个路径，不写技能目录名 `short-drama-ai-assets/registry.json`。
下一环 `short-drama-video` 按此取料写提示词、跑 dry-run、提交出片。
**卡改了，rev +1，由主管的依赖传播把已出织入片全标 stale。**

## 改动影响

| 改了什么 | 下游要重验 |
|---|---|
| 角色卡 / 服装图 | 全部已出织入片的服装与手 |
| 场景卡 / 四字道具 | 全尺寸细节帧看四字、屏幕内容 |
| 音色锚 | ASR 逐字比对、跨剧音色一致性 |
| 色温差 | 织入位前后 0.4s 叠化的观感 |
