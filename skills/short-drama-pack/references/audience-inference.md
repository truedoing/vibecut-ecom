# 人群推断：从剧情反推观众，不套模板

短剧的人群不能靠"中老年女性"这类模板。模板没法指导任何具体动作——
你不知道该叫"婶子"还是"姐妹"，该用灶台还是写字楼。

## 六维证据

| 维度 | 要看什么 | 例（八零憨妻） |
|---|---|---|
| 年代设定 | 服化道、器物、物价 | 借一斗米、土墙竹篱、麻花辫花布袄 → 八十年代农村 |
| 冲突类型 | 争的是什么 | 退婚、退彩礼、被叫"傻" → 婚姻由长辈定、女性被评价值 |
| 人物处境 | 主角在家庭里的位置 | 婆婆势利、丈夫不敢顶嘴 → 已婚女性、婆媳结构 |
| 台词价值观 | 反复出现哪些词 | "一家人""规矩""脸面""丢人现眼" → 熟人社会 |
| 场景 | 人在哪活动 | 院子、灶台、集市、门楼 → 农村/县城，不是都市 |
| 情绪曲线 | 憋屈还是爽 | 憋屈 → 反杀 → 需要代偿的人 |

## 年龄用事件年代反推，不靠感觉

```
观众现在年龄 = 观众在剧情设定年的年龄 + (当前年份 − 设定年份)
```

八零年代设定（取 1985）：

| 观众当时 | 现在 | 对这类剧的共鸣 |
|---|---|---|
| 20 岁（正在经历婚嫁） | 61 岁 | 极强，几乎是自己的事 |
| 15 岁（有青春记忆） | 56 岁 | 强，同龄人视角 |
| 10 岁（童年记忆） | 51 岁 | 中，记得年代但不记得婚嫁压力 |
| 5 岁（只有模糊印象） | 46 岁 | 弱，只剩怀旧 |
| 未出生 | < 41 岁 | 无，且可能反感"退婚/彩礼"叙事 |

→ **核心 50–65，边缘 45–50，明确不投 35 岁以下。**

这个算法换一部剧照样能用，只要换设定年份。**它比"我觉得是中老年"强的地方是：可以被反驳。**

## 输出格式（`elements.audiences[]` 每条）

```json
{
  "id": "au_001",
  "segment": "农村/县城 50–65 岁女性",
  "evidence": [
    "1985 年设定 + 借一斗米 → 有八零年代农村生活记忆",
    "退婚退彩礼 + 「怎么配得上我家建军」→ 亲历过婚事由长辈定的一代",
    "婆婆势利、丈夫不敢顶嘴 → 已婚女性、婆媳结构",
    "「我不是傻姑娘，我叫苏小满」→ 对被看轻高度敏感"
  ],
  "why_stop": "第 1 秒看到同龄人的处境，且她正被当众羞辱",
  "address_as": ["婶子", "大姐"],
  "exclude": ["35 岁以下女性（对退婚/彩礼是反感不是共鸣）", "都市白领（场景不共振）"],
  "confidence": "medium",
  "calibration": "上线 2 周后用后台观众画像校正"
}
```

必填：`segment` / `evidence`（≥2 条）/ `address_as` / `confidence`。
`confidence` 只能是 `high` / `medium` / `low` —— 内容推断原则上不给 high，除非有后台数据。

## 三个反例

- ❌ `segments: ["中老年女性"]` —— 无法指导称呼、场景词、语速，等于没写
- ❌ 套平台大盘数据（"快手短剧用户 8.5 亿"）—— 大盘不等于本剧观众，且无法反驳
- ❌ 用竞品账号的粉丝画像 —— 那是别人钩子的结果，不是这部剧的属性

## 校准

包里的 `confidence: medium` 就是承认这是推断。上线两周后，用后台观众画像回填：
年龄段、性别、地域分布。**若与推断偏差超过一档，回来改包，别改文案去迁就错误人群。**
