> **本技能不是入口。** 调度、门禁、状态台账走 `short-drama-supervisor`。
> 本技能**只做「准备」**：算一份「画面该怎么改」的参数表。
> **挂上去是装配器的事**——`short-drama-trailer/scripts/mix_trailer.py --dedup spec.json`。
>
> **为什么不自己出成片**：那样得对已拼好的 mp4 再跑一遍 ffmpeg，多压一次、画质掉一档。
> 交给装配器在组滤镜图时挂，全程只编码一次。

# 去重准备

> **性质（2026-11-14 张老师定，B 方案）**：独立技能目录，**不占流水线工位**。
> 不新增环节、不进 `status_overview.py` 的环节表、不动门禁、不给存量片子加重做标记。
>
> **硬规矩**：**去重的权重小于剪辑质量。** 加约束之后叙事质量不许下降。
> 落到工程上是两件事：① 只动画面，不碰清单任何字段；② 参数默认保守，宁可少套一段，
> 也不拿「画面变小」换去重读数。

## 何时使用 / 不要使用

- 使用：清单已定、准备装配，想要成品跟原剧「不那么像」（平台查重用）。
- 不要使用：选段与五幕重排（`short-drama-script`）、装配（`short-drama-trailer`）、
  图层文字 / 花字 / 片头尾（那是**修饰技能**的事，本技能一个字的文字都不产）。
- 纯剪片子里**没有强制**：不给 `--dedup`，装配器行为跟以前一模一样。

## 管什么 / 不管什么

| 管（只改画面） | 不管 |
|---|---|
| A1 画中画：主画面缩到 90% + 模糊底 + 白边框 | 段序、段长、选段、五幕、台词——**一个字都不改** |
| 原剧硬字幕清除（顺带做，见下） | 音频。**一律不做**：零解说纯剪靠原片台词讲故事，静音等于删内容 |
| A3 全片参数包：裁 8px、暗角、亮度 +3% 对比 +3% | 图层文字、花字、片头尾（修饰技能） |
| 循环扫光（12% 峰值 / 5 秒一循环 / 32° 斜向） | 变速（会撞时长账和台词节奏，`v0.1` 明确不做） |
| 一份装配器能直接读的参数表 | 自己拼成片、二次编码 |

**硬字幕怎么清的**：不单独做一步，也不建议用色块盖或局部模糊（巨量星图公告把「局部模糊」
明文算简单加工，两头不讨好）。正确顺序是 **先裁掉底部字幕带 → 再模糊 → 再叠主画面**，
字幕直接出画，干净、不糊、全自动。裁的是**背景层**，主画面完整保留，原剧字幕照旧在画面上
（只是跟着缩到 90%）。

## 输入 / 输出

| 项 | 说明 |
|---|---|
| 输入① 清单 | `runs/<剧>/<任务>/plan.json`（自动找 `plan.json` / `plan.silence.json`，或 `--plan` 指） |
| 输入② 句级表 | `assets/short-drama/<剧>/sentences/sentences_epNN.json`（挑段用；缺了也能跑，精度降） |
| 输入③ 配置 | `config/视觉参数_默认.json`（账号级，写一次所有片子共用） |
| **输出①** | `runs/<剧>/<任务>/dedup_spec.json`：全片参数 + 逐段参数 + 每段为什么套/不套 |
| **输出②** | 同目录 `扫光帧/0000.png…`：150 张循环帧（可关） |
| 给装配器 | `--dedup dedup_spec.json`。不给就完全不挂 |

## 用法

```bash
S=skills/short-drama-dedup/scripts/make_spec.py

python3 $S --drama 以真心守护至亲 --task D3_线一认不认这个妈 --dry   # 只看挑了什么，不写文件
python3 $S --drama 以真心守护至亲 --task D3_线一认不认这个妈          # 正式生成
python3 $S --drama X --task Y --a1 "S04_那道疤,S20_是我今天才看清"     # 自己指定，覆盖自动挑
python3 $S --drama X --task Y --no-sweep                              # 不叠扫光
```

然后装配：

```bash
python3 skills/short-drama-trailer/scripts/mix_trailer.py \
  --plan runs/<剧>/<任务>/plan.json --out 成片.mp4 \
  --dedup runs/<剧>/<任务>/dedup_spec.json --dry        # 先空跑
```

## 怎么挑「哪几段套框」——这里必须说实话

**机器只能判「套了会不会伤画面」，判不出「叙事上最该强调哪一段」。**

2026-11-16 用《以真心守护至亲》D3 的 22 个原片段实测过。人工挑的 5 段近景占比 67%～100%，
但**近景 100% 的另外 3 段人工没选**——那 3 段是动作或宣言，镜头贴着人脸，叙事重心却不在那儿。
所以近景占比再高也不等于「该强调」。

于是判据分两步：

**第一步，排除会伤的（硬排，不看分数）**
- 段长 < 3 秒：套框会一跳一跳
- 近景特写占比 < 50%：中景全景居多，套框后画面变小、场面反而看不全

**第二步，剩下的按画面语言排序，取前几段**
- 近景特写占比 × 3（镜头贴不贴人脸）
- 句间中位间隔 ≥ 2 秒 +1.5（不是抢话）
- 每秒不到半句 +1（节奏慢）
- 段长 > 14 秒 −1（套久发闷）
- 上限：`min(6 段, 原片段数 × 40%)`

**第三步，人说话。** 结果跟你的叙事判断不一样，就 `--a1` 自己圈。这是正规路径，不是补丁。

> 为什么不用「几个人说话」判吵架：11-16 第一版就是这么写的，结果人工挑中的 5 段里
> 3 段都被判成「吵架段」全排除了。抢话的特征是**句间空隙小**，不是人多。这条错了要记着。

## 参数（改配置，不改代码）

| 项 | 默认 | 为什么 |
|---|---|---|
| 主画面缩放 | 0.90 | **红线 0.85**，低于这个人物会被切、原剧字幕糊 |
| 模糊底 | `boxblur=10:1`，先缩到 1/4 再糊 | 全分辨率糊太慢，效果一样 |
| 模糊底亮度 | −0.08 | 压暗，主画面才跳出来 |
| 边框 | 白 30% 透明 / 6px | 看得出是「一块屏」，但不抢眼 |
| 裁切 | 8px | 本地实测对画面指纹 1.3 位，是全片参数包里最有效的一招 |
| 暗角 | 开 | 1.7 位 |
| 亮度/对比 | +3% / +3% | 单独对指纹 0 位，只做观感，**别当命门** |
| 扫光 | 开，12% / 5s / 5% 宽 / 32° | 张老师 11-14 拍板定版，人眼几乎看不出 |

**两条硬护栏写在代码里，改配置也没用**：主画面缩放 < 0.85 直接报错；套框段数超过
原片段数 40% 直接报错。要破得改代码，那是另一场讨论——不是参数。

## 验收（三步，缺一步都不算验过）

1. **装配空跑**：`mix_trailer.py --dedup spec.json --dry`，看是否认得出「A1 包装 N 段；扫光 开」
2. **时长必须完全一致**：挂与不挂各装一次，`ffprobe format=duration` 必须一模一样
   （本机实测 19.533333 对 19.533333）。不一致就是动了剪辑，不可接受
3. **看画面**：抽一帧套框段、一帧不套段，人眼看三件——字幕清干净没、人物有没有被切、
   模糊底有没有留字影

## 已知带伤与边界

1. **没测平台读数**。「更不像原片」只是设计意图，这套参数能在查重模型上压低多少，**没有任何数字**。
   本技能不给任何效果百分比承诺。
2. **语义层不变**：台词、剧情、人物还是那部剧，这层躲不掉。只求把读数往下压，不求百分百。
3. **合规边界**：巨量星图公告把「只加滤镜、局部模糊」定性为简单加工。A3 的调色在这类边缘，
   重心放 A1 改画面格局，不靠调色。
4. **没开画面打标时一段都不套**。看不出景别就硬套框，可能把大场面压小、反而伤画面。
   宁可少做一层。要 A1 就开打标或 `--a1` 指定。
5. **音频去重没做**，是主动取舍不是遗漏。
6. **拆出来的「修饰技能」还没建**：图层文字、花字、片头尾、点睛句表仍在
   `runs/以真心守护至亲/D3_线一认不认这个妈/build/去重预览/全片版/` 的一次性脚本里。
   本技能只搬了去重那半。
7. **花字与硬字幕同句会叠两行**：11-14 裁定按「强调」定案，那是修饰技能要解的题，与去重无关。
