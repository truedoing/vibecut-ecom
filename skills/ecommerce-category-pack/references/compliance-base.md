# 通用合规基线（技能自带，不进品类包）

品类包的 `compliance_ext` 只写 `base_redline_ref` 指向本文件，**不复制正文**。

## 立场

**商家视角、促销优先。** 本文件是**兜底检查**，不是写作起点。
写作从 `selling_point_map.usable_rewrite` 出发；这里列出的词，是写完回头扫一遍用的。

## 四类真正要避的红线

| 类 | 说明 | 典型词 |
|---|---|---|
| **A · 疾病功效** | 普通食品（SC）不得宣称治疗/预防/调节身体机能 | 降三高、降血糖、降血脂、软化血管、清肠、排毒、治便秘、增强免疫、防癌、延年益寿 |
| **B · 无依据虚假比较** | 无检测/无出处的对比与换算 | 媲美 X、比 X 更有效、一勺顶 X 碗（无折算依据） |
| **C · 无认证宣称** | 拿不到证书编号就不能说 | 有机、零农残、蓝帽子、PICC（未核编号）、检测认证、央视上榜、专家/医生/营养师推荐、秘方 |
| **D · 虚假价格稀缺** | 价格与紧迫感必须实时真实 | 库存不多、错过再等一年、最后一天、限时、名额有限、马上抢光 |

**外加一条安全底线（不是促销限制）**：过敏原反向宣称。
包装若写明「生产线也加工花生/芝麻/坚果制品」，绝不能说「不含坚果」「过敏也能吃」。

## 广告法通用绝对化用语

国家级 / 最高级 / 最佳 / 第一 / 唯一 / 100% / 纯天然 / 绝对 / 顶级 / 最安全。
（「100% 天然甜」→ 改成「没加白砂糖，甜是原料自己的」即可保留内核。）

## 兜底禁词表

按范围分三档，**扫描时只扫文案正文与 `usable_rewrite`**，不要扫本文件自己。

### 基础档（所有品类所有人群）

清肠、排毒、控卡、燃脂、减肥、瘦身、治疗、预防、疗效、三高、血压、血糖、血脂、
便秘、增强免疫、防癌、延年、软化血管、医生、营养师、秘方、央视、专家、药用、
功效、调理、祛湿、有机、零农残、蓝帽子、库存不多、错过再等、最后一天、限时、抢光。

### 人群专属档

见 `references/platform-audience.md` 的三张表（中老年 / 中年女性 / 给妈妈买）。
**属人群属性，不进品类包。**

### 品类专属档

由各品类包的 `compliance_ext.category_specific` 提供。
例：虎坚果酱的「不含坚果 / 坚果过敏也能吃」；羽衣甘蓝的「一条顶半斤蔬菜（需换算依据）」。

## 遇到风险词怎么处理（顺序不能反）

1. **先试改写** —— 保留商业内核，换风险谓语（见 `method.md` 第三节）
2. **再判类别** —— 是否落在四类红线？是 → `status: blocked`，`usable_rewrite: null`
3. **最后兜底扫描** —— 用上面的词表回头扫一遍成品

> 不要跳过第 1 步直接禁用。把卖点当违规一刀切，是把商家的活干成了审核的活。
