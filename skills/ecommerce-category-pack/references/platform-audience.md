# 平台 × 人群参数表（技能自带共享参数）

**这是平台属性，不是品类属性。** 卖羽衣甘蓝还是虎坚果酱，视频号中老年都是 3.8 字/秒。
所以本表放技能里，**绝不复制进品类包**——每个包复制一份就会漂移。

品类包的 `compliance_ext.shared_overlay_ref` 指向本文件即可。

## 实际投放前提（2026-10-20 确认）

**投微信视频号，目标人群年纪偏大**，不是抖音、不是年轻人。
视频号流量来自**社交推荐**不是算法推荐 → 转发引导比完播钩子更值钱。

## 三张人群专属红线表

在 `compliance-base.md` 基础档之上叠加。

### 中老年（监管最严人群）

降三高 / 降血糖 / 降血脂 / 软化血管 / 清肠 / 排毒 / 治便秘 / 增强免疫 / 防癌 /
延年益寿 / 更年期 / 骨质疏松 / 补钙 / 老年斑 / 改善睡眠 / 医生推荐 / 营养师认证 /
央视上榜 / 秘方。

**文案只讲五件事：口感、方便、配料、价格、习惯。**
改文案加新句子时按这张表再对一遍。

### 中年女性 ·「关爱自己 + 健康」组合

额外禁用：抗衰 / 抗氧化 / 延缓衰老 / 显年轻 / 去皱 / 淡斑 / 美白 / 补气血 /
气血不足 / 调经 / 调节内分泌 / 更年期 / 卵巢保养 / 胶原蛋白 / 美容养颜 /
减肥瘦身 / 改善睡眠 / 缓解疲劳 / 提神 / 增强体力。

**安全写法**：把「关爱自己」落在**时间和允许**上（每天有一分钟是自己的、
这次别又算了），不落在身体改善上。痛点命名要命名**心理状态**（不是累，
是把自己排到最后），且**不能说喝了能改善**。

### 给妈妈买 · 全产品硬规则

**「保健品」三个字永不进文案。** 产品是普通食品，情感定位（孝心、惦记）保留，
产品身份表述全部回避：保健品 / 补品 / 营养品 / 补补身体 / 增强抵抗力 / 增强体质 一律禁用。
指代用「那些瓶瓶罐罐」「柜子里那些」「一瓶几百的」。

两条配套红线：
- **不替妈妈做使用证言**（不说「我妈喝了以后…」）——既是功效暗示也不可证实
- **孝心不能当功效包装**（「辛苦一辈子该补补了」是把产品往功效上推）

投放前必须先确认产品身份是普通食品（SC）还是保健食品（蓝帽子）——
中老年 + 暗示功效 + 子女孝心营销是职业打假人盯得最紧的组合。

## 视频号专属

- **转发引导**：流量靠朋友点赞扩散，可把第 14 段换成「转给你那几个老姐妹，
  让她们也看看配料表」。**挑一条改就够，三条全改显得刻意。**
- **逆向 CTA**：「先买一盒，别一上来囤半年」「先别囤」「这次别又算了」——
  不写库存紧张、错过再等，反而更像真人推荐，也避开 D 类虚假稀缺。

## 品类包怎么用这张表

建包时**只做两件事**：
1. 在 `selling_point_map` 里判断某条改写是否适配目标人群口径
   （例：「仙女饮品」是抖音网感，中老年版要换成「早上冲一杯」）
2. 若厂商定位与实际投放人群冲突，写进 `conflicts`，**交人定**

其余参数由下游文案技能从本表注入，包里不存。
