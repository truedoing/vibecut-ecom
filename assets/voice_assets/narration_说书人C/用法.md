# 解说音色资产 · 说书人C

张老师 2026-11-20 从四个候选里挑定的解说音色。所有剧共用，不属于任何一部剧。

## 这是什么声音

男声，中音有厚度，像茶馆里说家长里短的奇闻，转折处压低卖关子。适合"有人慢悠悠跟你讲一件离谱事"的解说，不是播报、不是广告腔。

- `voice.mp3`：**声音样本（锚）**。下次克隆就用它，这是这个音色的本体。
- `sample.mp3`：试听样本，念的是《穷妈的底牌》那两句解说词。
- `card.json`：机器读的音色卡，写着描述、怎么调接口、已知边界。

## 下次怎么用它配解说

关键是**拿 voice.mp3 当声音样本，让 MiMo 照着念新词**，出来还是同一个声音。不用重新描述音色，也不用重造锚。

用 MiMo 的克隆接口（`mimo-v2.5-tts-voiceclone`）：

```
POST {MIMO_BASE_URL}/chat/completions
headers: api-key: {MIMO_API_KEY}
body:
  model: mimo-v2.5-tts-voiceclone
  messages: [{role: assistant, content: 新解说词}]
  audio: {format: mp3, voice: "data:audio/mpeg;base64,<voice.mp3 的 base64>"}
取 choices[0].message.audio.data，base64 解码存成 mp3
```

配置从 `.env` 读 `MIMO_BASE_URL` / `MIMO_API_KEY`，别写死在脚本里。

配好的 mp3 再交给 `duck_narration.py`，用配置里的 `audio` 字段指过去叠进成片（原声自动压低、说完回来，画面不动）。

## 两个要说清的边界

1. **现在的叠音脚本还不认这个音色。** `duck_narration.py` 目前只会调微软 edge-tts，不认 MiMo 音色资产。这次是先用 MiMo 把两句词克隆成 mp3、再用脚本的 `audio` 字段叠进去。要做到"以后配解说自动用这个音色"，得改脚本支持 MiMo——**这一步还没做**。
2. **这个音色不是免费的。** edge-tts 不花钱的说法只对微软音色成立；MiMo 走接口按量计，新词克隆比造锚便宜，但要看用量。
