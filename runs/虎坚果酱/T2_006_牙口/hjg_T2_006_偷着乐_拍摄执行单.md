## 片子的两段式

```
0–15s   钩子 · AI 生成（林岚独白）
        自白型：瞒着女儿偷偷买酱偷偷吃，落点"承认自己馋这一口"
15–52s  混剪 + 旁白（林岚锚，与钩子同一人）
        配料 → 数值 → 产地工艺 → 吃法 → 价格 → CTA
```

## 卖点三自测

- **需要感**：抹酱开封两周吃不完 + 一瓶五十多舍不得天天挖 → "偷偷买、偷偷吃"把两件事都接住
- **可信度**：配料三样 / 9.2g 膳食纤维 / 图木舒克产地，全部 verified 或有出处
- **唯一性**：竞品能不能原样说这句话？——"藏起来偷偷吃"是行为戏，配合自白人设，一般抹酱不敢这么演

## 后半段组合

主角=配料 · 顺序=配料→数值→产地工艺→吃法 · 逼单=低门槛先一罐（与近 3 条不同指纹：T2_005 走的是配料→数值→吃法，本条插入产地工艺作信任打断）
