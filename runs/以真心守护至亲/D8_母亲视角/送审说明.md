# 送审说明 · 以真心守护至亲 / D8《妈手里那副牌，一张都没为自己打》

> 2026-11-22。第 8 条片子。纯剪、零解说、零 AI、零花费。12 段，2 分 11 秒。

## 这条是什么

母亲视角。前 7 条都没从这个位置看过她：

- D6《穷妈的底牌》是**旁观者视角**——观众跟周家人一起把老太太当穷亲戚，最后才发现看走眼，靠的是"信息反转"。
- 这条**反过来**：观众第一秒就知道她把五十斤黄金做成轮椅、刷黑漆装穷，只为试两个失散 17 年的女儿。全片看的是——她手里全是牌，却一张都不为自己打。
- 受力结构：她跟别人不较劲，她跟自己较劲。明明能翻牌（亮身份、亮股份、亮那份项目价值），每一次都收了回去：被撵不辩、被问住处只护女儿的脸、主动退到外面、护资料不说破、递材料说成举手之劳。

## 怎么排的

副线型，只取三幕（Tease ＋ 三拍拒绝 ＋ Button），2 分 11 秒。前 45 秒每段都是一次拒绝或反击。

| 幕 | 段 | 内容 |
|---|---|---|
| Tease 交底 | S01 | 她自报底牌：黄金做轮椅、刷黑漆、穿破衣服去试女儿 |
| Establish 三拍 | S02–S04 | 认亲被否 → 全部家当被嫌 → 她唯一一次说出委屈："为什么非要拿这副穷样子试他们的心" |
| Escalate 能翻不翻 | S05–S09 | 大女儿认她 → 被逼到墙角只问"我把你往哪放" → 主动退到外面 → 把亏欠揽自己身上 → 护资料不解释 |
| Brake 最静 | S10 | 她看懂女儿被扔的项目，全片唯一一次没吵架 |
| Button 落点 | S11–S12 | 递材料说成举手之劳 → 女儿反过来把床让给妈、留灯叮嘱；妈躺在床上含泪说"一起想办法" |

## 落点为什么是这句

落点在妈那句"以后有事，咱们一起想办法"——前 7 条的落点分别停在"她手里还剩几张牌""向后的账一笔笔算""她一个字没承认自己是谁""没有一样是她的""那是她替你们挡的那一下""她只是替你递材料""有人会看"。这句没撞过。

按句级表核对（ep17）：
- "妈今晚你睡床""我打地铺""床边给你留着灯"——**女儿许宁说的**，是女儿反过来照顾妈；
- 落点"好以后有事""咱们一起想办法"——**妈林秀兰说的**，画面是她躺在床上、眼眶发红含泪。

含义因此更清楚：忍了整片、一直护着女儿的妈，第一次被人接住——女儿让她睡床、给她留灯、叮嘱复查。妈手里全是牌一句没提，只回了一句"咱们一起想办法"。这是母亲视角的收束：她终于不用再一个人扛。
