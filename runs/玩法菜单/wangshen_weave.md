# 玩法卡 · 王婶旁观（wangshen_weave）

> 一道菜一张卡。本卡只写「怎么选、去哪找、什么时候算改版」，
> 具体怎么做分别写在三份技能文件里，**本卡不复制它们的内容**。
> 2026-11-10 建第一张；适用条件目前只从 D5 婆婆线一个用例归纳，尚无第二条例证，
> 改动要留痕，别当成已经验证过的规律。

## 一、什么片子适合用（方向卡照这栏做推荐）

| 条件 | 为什么 | 不满足会怎样 |
|---|---|---|
| 开场有一句「打人」的强台词，观众有话想说 | 王婶是替观众说观后感，情绪最满时出场共情零成本 | 没情绪可接，插进来像硬加 |
| 第一场后有黑场或能留黑场，下一段是回跳 / 换场 | 这个位置既是消化位也是导航位，她一句能把观众锚住 | 得改动整张清单去造位置 |
| 题材生活化、有年代感，容得下「隔壁院大妈」这个声音 | 区隔靠色温差和固定道具，调性差太远会出戏 | 观感突兀 |
| 愿意花一次出片的钱，并接受两道人审 | 生成是整条链唯一花钱的环节 | 不该点 |

**默认不点。** 纯剪够用、片子要极短、剧的调性不适合插旁观者、或四字道具还没验证通过时，
就选「不点菜」。方向卡写推荐理由时要讲清命中了上表哪一条，别凭印象。

## 二、要准备什么

- 角色资产三件套：无脸服装图 / 无脸场景图 / 音频锚，清单在
  `assets/short-drama/ai_assets/registry.json`。
- 插入位上下文：第一场（前一段）的台词与尾画面，供写观后感台词、以及 AI 片开头电视屏用。
- 两道停：台词人审通过、出片前试跑核请求体。出片后逐字比对台词 + 抽帧。

## 三、生成出来的东西插在哪

第一场后的黑场位，**整段插一次**；插完整段后原黑场取消（屏即转场）。
清单里只体现为「留了一个插入位」，不写玩法名字——装配器只认位置，不认名字。

## 四、花多少钱、哪几处人过目

| 项 | 值 |
|---|---|
| 出片规格 | 10s / 480p / 9:16（实际输出 496×864） |
| 成本 | 约 2 元一次（张老师实测口径；10 元是 15s 带货片老数） |
| 人过目 | ① 台词人审（历史上多次被否，不审不花钱）② 试跑结果报出后才提交 ③ 出片后逐字比对 + 抽帧 |
| 硬限制 | 参考图含真人（**含 AI 生成的脸锚帧**）一律 400 拒；「王婶说剧」四字道具必须出现，**目前尚未出片验证通过** |

## 六、现在第几版 / 什么时候加一

**第 1 版**。版本只在 `runs/工作台.json` → `shared.ai_strategies.wangshen_weave.rev` 记一处，
本卡不另记一份。

- 改本卡任一栏，或改三层里任何一条硬规矩（提示词骨架、出片参数、验收方式、插入位规则）
  → 由主管把工作台这道菜的 `rev` 加一；进度脚本会自动把点了这道菜的片子标「要重做」。
- 只改错别字、补例子、补历史说明 → 不加版本。
- 新增一道菜：新建一张卡 + 在工作台菜单加一项（带 `recipe` 路径和 `rev`），
  已有片子一条都不动。

> 「适合什么片子」只写在本卡里，工作台菜单项只留卡的路径，不复制一份——
> 同一件事记两处，慢的那处一定会落后（第 35、36 环两次教训）。
