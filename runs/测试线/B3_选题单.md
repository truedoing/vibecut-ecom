### T9007 我来找建军哥（门槛线）

退婚 → 一个人走几十里 → 到门口被堵 → 全包重活 → 建军说「不管娘同不同意我都要娶她」。

- 开场三拍：彩礼退回来了 → 他们说你这病好不了 → 那我去找建军哥说清楚
- 中段反击：「刘婶，我家的事轮不到你插嘴」「我不怕干活，我就想留在这儿」
- 落点：建军硬气 + 婆婆松口「明天去镇上给她扯块布」

**这条是三条里唯一的完整弧线**（主角主动出发 → 被挡 → 站住 → 被接受）。

### T9008 一斗米到一垄菜（刘婶线）

造谣被推 → 界石 → 拔菜苗被当众判赔 → 反送菜种。

- 开场用最强冲突：刘婶满村说「周家那傻媳妇把我推了个跟头」
- 中段：界石之争、菜苗对质「谁看见了？一个傻子说的话也能信？」
- 落点：「刘婶，给你，菜种。你自己种，种了就不许再拔了」

### T9009 你是我的闺女（名分线）

王婆子带赵四上门想讨便宜 → 倒叙她怎么被这家人认下来 → 婆婆当众认闺女 → 传镯子。

- 开场用结果钩人：赵四说「当初王婆子还说要把你说给我」，她答「不记得」
- 倒叙：当众娶你 → 婚礼糖水 → 全家福 → 传陪嫁「你就是我亲闺女」
- 落点：「我有家，两个家」→ 三十年的镯子 → 「这姑娘是咱们村的福气」

**这条是三条里最狠的一条**，倒叙结构，开场就给人「她现在过得很好，旧账来的人被堵回去了」的爽感。
