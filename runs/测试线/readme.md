# 测试线

测「一次过率」用的，跟生产片子分开放，互不干扰。

- 怎么测、怎么判、怎么算：`docs/测试线_v1_一次过率_测法.md`
- 数据：`台账.csv`（每轮审核一行）
- 看数：`python3 runs/测试线/算账.py`
- 看耗时：`python3 runs/测试线/打点.py show`
- 片子物料：继续放在 `runs/八零憨妻/` 下，这里只放台账与结果

## 按轮隔离（2026-11-12 张老师定）

**每轮测试开始前，台账清空，之前生成的一律不算，就当没生过。**

- 台账只装「当前这一轮」的行，不跨轮累计。要比较两轮，看各自轮次目录下的存底。
- 一轮结束时：把 `台账.csv` 复制成 `轮NN_台账.csv` 存底，然后清空（保留表头）。
- 机器侧耗时用 `打点.py` 记，跟台账分开：台账记"人审花了多久、过没过"，打点记"机器跑一个环节花了多久"。
