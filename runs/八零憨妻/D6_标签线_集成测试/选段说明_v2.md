## 二、为什么副线不该做五分钟

**背景**：v1 是把标签线当主线做的——Tease、三拍拒绝、反击加回撤、急停、当众认，
五幕一幕不少，15 段铺到 296 秒。技术上全绿，内容上却有两处半句切点，
而且中段 ep14–15 连着六个「有人使坏 → 全家对质」的来回。

**转折**：张老师一句话把定性改了——「这个冲突应该是副线，复线的冲突没那么强烈」。
这不是在说剪得不好，是在说**片长和取段密度从一开始就选错了规格**。
婆婆线（D5）是主线：态度从拒到认，有完整因果链，矛盾一次比一次重，值得 325 秒。
标签线是副线：同一种场面反复出现，没有要铺的链条，第三次之后观众已经懂了，
第四次到第九次就是边际递减——这就是「单调」的来源。

**结论**：副线不套主线的五幕。只取三幕：最强台词开场 → 三次拒绝 → 当众认 / 点题。
中间那串「反击→回撤→再反击」是主线弧线的张力装置，副线没有弧线，硬加就是「转化太多」。
**2–3 分钟收住，只抽经典场。**

**方法论**：方向卡上从此多一栏——「这条线是主线还是副线、打算多长」，跟圈故事线一次点头。
判据不是哪条更重要，是**有没有一条从头到尾的因果链、冲突是不是一次比一次强**。
已写进 `short-drama-script` 第 1 步、第 4 步、第 6 步与影响表，
`short-drama-trailer` 时长预期、人审表模板、主管开工三问与影响表同步。

## 四、砍了哪些场、砍掉的是什么前因

| 砍掉的场 | 前因 / 它本来在讲什么 | 砍了会不会看不懂 |
|---|---|---|
| **S05 种什么菜**（ep14 21–31） | 「一个傻子种什么菜」，她只回一句「等菜长好了给你也送点」 | 不会。这句的功能是又一次「叫傻」，前三次已经立住 |
| **S06 她不是傻子**（ep14 37–61.5） | 菜苗被拔，建军当众说「她不是傻子」 | 会丢「菜苗」这条线索，但那是邻居线的事，不是标签线 |
| **S07 村长判赔**（ep14 62–88） | 举证之后村长判刘婶赔菜苗钱、道歉 | 不会。它是邻居线的收尾 |
| **S08 又造谣**（ep15 1–20.7） | 刚判完赔，刘婶满村说她推人，回撤续命 | 不会。回撤是主线弧线的装置，副线不铺 |
| **S10 送你菜种**（ep15 94–122.5） | 她递菜种「种了就不许再拔了」，旁人「什么叫以德报怨」 | 略薄：村代表那句「用真心换来了全村的尊重」少一层铺垫，但句子自带因果，能懂 |
| **S13 我闺女**（ep17 39–55） | 哥哥托付、棚子要塌、她撑住棚子、婆婆认闺女 | 不会。这属婆婆线（D5 主轴）和力气线，不是标签线；**而且 v1 切在半句上的正是这一段** |

**整串砍的理由**：S05–S10 是方向卡里单列的 B 线「邻居线」——刘婶的小恶从一斗米滚到一垄菜苗。
v1 把它并进来凑「反击 + 回撤」，结果变成菜苗被拔 → 举证 → 判赔 → 造谣 → 再举证 → 递菜种，
**六个来回、强度不涨**。这正是张老师说的「转化太多、显得单调」。
留下的 S09 自己是一场完整小冲突（有人告状 → 逐条对质 → 哥信你），不靠前面铺垫也看得懂。

**用集变化**：ep14 全砍、ep15 只留一场、ep17 只留村代表一场；用集 8 → 7
（ep3/5/11/13/15/17/18）。第 20 集大结局素材仍然一律不进成片。

这轮回原片**逐秒抽帧、裁字幕区目视**，把两集的时间码校正到「句子出现的那一秒」、补上漏句，
台词文字**仍然只存 `lines/` 一份**，索引里的时间码视图同步重渲染（视图不是副本）。
两集各加一段 `_subtitle_recheck` 记录实测秒数与「排切点仍要目视、别照抄 t」的规矩；
11-10 那条 ASR 复核记录**原文保留、标注部分取代**。
其余 17 集没做这轮复核，切点仍须目视——这是已知的欠账，不装作全好了。

## 六、段与段之间是「但是 / 所以」

| 连接 | 关系 |
|---|---|
| S01 → S02 | **所以**：她敢当面讨米，才有人议论周家白捡个劳力 |
| S02 → S03 | **但是**：她说「因为这是我家」，镇上照样有人「傻子穿新衣裳不也是傻子」 |
| S03 → S04 | **所以 / 但是**：婆婆第一次替她挡了话，才走到办婚礼；席上仍有人砸场 |
| S04 → S09 | **但是**：石碾震住全场，转头还是有人告状「我妹打人了？」 |
| S09 → S12 | **所以**：一次一次当众把话说明白，才有村代表「用真心换来了全村的尊重」 |
| S12 → S14 | **所以**：村里认了，她才说得出「我嫁人了，我有家了」 |

比 v1 少 5 处转折，没有一处变成「然后…然后」。
