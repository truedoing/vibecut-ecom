## 三、段间连接（But / Therefore，事后按段意还原）

- S01 **但**她不走 → S03 当街自证「我不走」
- S03 **因此**被拽、被贴标签 → S04 只能坐门口守夜
- S04 **但**赶不走 → S05 改口「留下也行」，条件是把重活全包
- S05 **因此**手磨破 → S06 考核中途停手（第一次态度松动）
- S06 **但**还没认她 → S07 端粥被拒、背身问手
- S07 **因此**看似护上了 → **但**马上 S08 回撤：刚护完就派她扫院子（false victory）
- S08 **因此**张力续命 → S09 高烧背人，落点「护定她了」
- S09 → **急停** S10b 黑场 → S11 刘婶说亲，婆婆当众挡回去
- S11 **因此**立场翻完 → S13 当众认 → S14「我有娘了」→ S15 收尾卡
