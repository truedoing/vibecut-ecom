## 一、定位（v0.3 改写）

**解说型预告**：以解说的叙事流畅性为主线，原剧片段作为**证据画面**配合穿插。
不是缩短版原剧，也不是原声混剪——是**用解说把故事讲一遍，用原片画面证明它**。

两条不可混淆的线：

- **解说轨**：承担叙事连贯，观众靠它听懂「谁在争什么、为什么、结果如何」。
- **原剧轨**：承担真实感与冲击。**精彩的原剧片段不要截断**——一段演得好的戏，观众要的是完整的一击，不是一半。

**这与 v0.2 的关系**：v0.2 那套「五幕 + 三拍完整单元 + But/Therefore」仍然全数有效，它管的是**骨架**。
v0.3 补的是**血肉**：血肉怎么长在骨架上、怎么不互相打架。

## 二、两层边界（11-22 张老师定，防剧透只防在成品层）

| 层 | 范围 | 为什么 |
|---|---|---|
| **成品范围**（能进片子的素材） | 全剧前 60%（60 集剧 → 36 集） | **这才是防剧透的真正关口。**观众看的是成品 |
| **台词解析范围（OCR）** | **全剧 60 集** | 解析的是给自己看的数据，不是给观众的。**做文案要对全剧有理解**，只懂前三分之一写不出好解说 |
| **画面打标范围（VLM）** | 全剧前 60%（36 集） | 打标贵，而且只有进成片的才用得上 |

**旧口径（已被取代，保留）**：「整部剧只解析前 60%，后 40% 一集都不碰」——
那是把防剧透做在了解析层。成品范围已经限死，解析后段没有剧透风险，白白牺牲了文案的全剧视野。
**新口径**：解析放开到全剧，成品照旧锁 60%。

> **边界口径只有一个标准（11-22 张老师拍板）**：成片范围 = 全剧前 60%，不再为泄底点单独切一刀。
>
> 《以真心守护至亲》原口径「1–17 ＋ 19–31」作废，回归 **1–36**。
>
> **但剧透点没有消失，只是换了层去拦**：
> ep18–19（喊「林董」）、ep32–38（身份彻底揭晓）是身份揭穿段，
> **选段时必须避开这两处**——范围一个标准，剧透在**选段层**拦，不在范围层拦。
>
> 这条区分很重要：**范围规则负责省事，选段纪律负责防剧透。**
> 混在一起的结果就是「为了防剧透把范围切碎」，白白丢掉一倍的素材。

## 二·补、全剧理解用在哪、不用在哪（11-22 实测补）

「做文案要对全剧有理解」——这句话落到操作上是**四个用法、一个禁用法**。

| 用法 | 干什么 | 实例 |
|---|---|---|
| **选** | 判断哪些段值得留 | ep57「赌是我输了／是我说错了对不起」是全剧最硬的一句回收 —— 知道它在，才敢把 D7 的结尾停在 ep16 |
| **序** | 排因果链，不是排好看程度 | D7 的三件锁链（工作→名誉→住处），顺序是全剧看下来的「她一次比一次狠」 |
| **落** | 知道悬念在哪兑现 | 七条片子的悬念在全剧**全部有兑现** —— 这才敢做第二条、第十条 |
| **写** | 判断哪句该留给原声 | 「招聘该看他能不能做事」是妈妈护女，「我选的是带我妈回家」是女儿表态 —— 两句都留给原声，旁白一个字不碰 |

**禁用法：解说词里不能说画面之外的事。**
观众看第三分钟时只拿到了画面里的信息。解说突然说「她妈其实是这家公司董事长」——
观众跟不上，这不是伏笔，是剧透 + 掉线。

> **一句话规矩**：全剧理解用在**选、序、落、写**四字上，不用在「补」。
> 要补的信息，说明这段画面本来就不该选。

**推论（11-22 查实）**：全剧理解会让主题变深，这本身又变成下一条片子的原料。
D7 原本是「丈夫给的每一样都是锁链」，全剧看完，剧的真实回答是
**「锁链和梯子的区别，不在给不给，在替不替你做主」**（ep19 母亲安排岗位但要求「别让招聘变成认老板的女儿」；
ep35 母亲主动撤下给周承的股权；ep51「妈得学着坐在外面等，不替你把路都选好」）。
**主题深一层，下一条片子的角度就多一个。**这是「一剧多条」真正的来源 —— 不是换悬念，是换侧面。

## 三、解说怎么写：三种手法分工（第 6 条）

**病因诊断**：D7 实测——**解说词里 36.4% 的文字，在重复画面同期正在说的原话**（最差一段 55.1%）。
观众等于把同一句话听了两遍，第二遍是旁白复述，没有信息增量，只会觉得「这人在重复我」。

**根因不是写得不好，是没有分工意识**——解说被当成了「台词字幕的替代品」。

### 三种手法，各管一段

| 手法 | 干什么 | 例子（同一段画面，三种写法） |
|---|---|---|
| **说画面** | 讲画面里有、但没被说出口的东西：动作、表情、空间、物件、镜头怎么切 | ❌「她说这婚我不结了」 → ✅「戒指被她推了回去，指尖在盒沿上停了半秒才松开」 |
| **说台词** | 只在**原声此刻没说、说了也听不清、或要提前预告**时才说 | ❌ 同期正在说的那句照抄一遍 → ✅「她接下来的这句话，说完这场婚礼就散了」（然后切原声） |
| **说内心** | 讲观众看不见的：动机、言外之意、没说出口的那半句 | ❌「你给我这些是为了让我什么都听你的别碰我」 → ✅「她终于听懂了：对方给的每一样，都是拴她的绳」 |

### 硬指标：同步复述率

**定义**：解说的字句中，与该段画面**同期正在说的原话**重合的部分，占解说总字数的比例。

- **每段 ≤ 15%，全片 ≤ 8%**（钉子句例外，单独标注并说明为什么必须重复）。
- **自查方法**：把解说词和该段原台词并排读，凡是两边出现的**连续 3 个字以上**相同，即算命中，必须改写或删掉。
- 命中的是「同步复述」；换了说法讲同一个意思**不算**（那叫解读），但也要警惕别处已经说过。

### 配比要求

一条片子的解说**不能每段用同一种手法**。至少要有：
- 2 段以上是「说画面」或「说内心」为主（不碰台词）；
- 手法切换跟着**情绪起伏**走，不跟着段落序号走。

### 留白优先

**重要的原声段落，第一选择是留白（不配解说），不是复述。**
D7 的 S07（丈夫摊牌）就是对的：钉子让观众自己听见，解说加一句都是稀释。

## 四、情绪指令怎么传给配音（第 5 条）

解说稿的情绪标注**必须传给配音模型**，否则一整条片子平得像念稿。

**已验证的正确做法（11-22 实测）**：

| 传法 | 结果 |
|---|---|
| 把情绪前缀拼在朗读文本前 | ❌ **会被念出来**——「（冷，把「是谁递的」点破，不带情绪）」直接进了配音 |
| `messages` 里用 `system` 角色 | ❌ 接口 400 |
| `【不朗读】`标记 | ❌ 无效，照念 |
| **顶层 `instructions` 字段** | ✅ **有效，且不进朗读文本** |

```python
payload = {
    "model": "mimo-v2.5-tts-voiceclone",
    "messages": [{"role": "assistant", "content": text}],   # 只放要念的
    "instructions": "（压着，一字一顿，替这老太太说句话）",   # 情绪走这里
    "audio": {...}
}
```

**规范**：每段解说稿都带一档情绪指令，分三档——

| 档 | 用在哪 | 指令写法 |
|---|---|---|
| 深 | 全片关键的情绪峰值（爆发、定音、反转） | 写清**演法**和**立场**：「压着，一字一顿，替这老太太说句话」 |
| 中 | 推进叙事的中段 | 写清**语气**和**速度**：「短，干脆，替她把话撂下」 |
| 浅 | 交代性的一句 | 「别多说」「平铺」 |

**指令要写「怎么演」，不是「演什么情绪」。**「悲伤」是标签，「压着，一字一顿」才是演法。

## 五、选段：精彩原剧片段不要截断（第 4 条）

这是「解说为主」带来的**选段连锁反应**：

- v0.2 的选段是「按台词锚点 from/to 定位」——天然会掐头去尾，为了卡准一句台词而切进切出。
- 解说为主之后，**原剧片段是证据，证据要完整**：观众看到的是一场戏，不该看到半场。
- **新规则**：
  1. 选段以**完整场景/镜头组**为单位；
  2. 场景过长（> 25 秒）才允许切，切点落在**镜头边界**（不切在人物对白中间）；
  3. 解说在场景内部铺开，而不是在场景边界切换；
  4. 一场戏演得好，就整场留。

> ⚠️ **工程待改**：`pickpoints.py` 目前只支持台词锚点定位，还没有「按镜头组切」的模式。
> 这条要落到脚本里，需要另开一轮。

## 五·补、说错人比说不清更糟：三方交叉验证（11-22 实测）

自动打标会认错人，**三个方法各错各的**，实测三处矛盾：

| 位置 | 句级表 | 镜头打标 | 语音转写（带说话人分离） | 语义 | **实判** |
|---|---|---|---|---|---|
| ep6 38.00「轮不到您教我怎么招人」 | 周德海 | 中年男性 | 与周德海同组 | 用敬称「您」＝晚辈对长辈 | **许宁**（句级表错） |
| ep9 15–19「证还没领／这婚我不结了／戒指我也不戴」 | 周德海 | 中年男性「冷面拒婚」 | 同一说话人连续说完 | 画面 14.6–17.9 是新娘红眼盯戒指盒 | **许宁**（句级表错） |
| ep13 44.00「记得谁让他换的」 | 周德海 | 中年男性拿白纸 | — | 公公对女儿说 | **周德海**（标对了） |

**为什么三个方法都靠不住**：
- **句级表**会认错人；
- **镜头打标**会认错主体（过肩镜头里画面主体是别人，说话的人在画外）；
- **语音分离**分不开音色接近的人（母女都是女声、句间无停顿就并成一组）。

**规矩**：
1. 凡是要当**落点句**、要写进 **angle 的直接引文**、要判断**谁在场**的段，**必须三方交叉验证**；
2. 三方对不上又判不了的，**不许写进解说词，也不许当落点**——宁可换一句落点；
3. 画面证据优先用 `mouth_visible`（谁在开口）＋ `action`（谁在做动作）组合，比 `who` 字段可靠；
4. 引用原话必须**回原片逐字核**。「证还没领」写成「证都没领」这种，同音近音差异会让复述率检测漏判——**检测器有洞，文案里也得防**。

> 这条对全剧解析同样成立：ep19–60 的 41 集台词里凡涉及「谁做的」的判断，都要过这道验证。

## 六、成本档（11-22 实测，见 `成本实测_VLM画面打标_20261122.md`）

| 项 | 结论 |
|---|---|
| 缩图边长 | 640 → **384**（每镜仍抽 3 帧），省 27.3%，质量与现状同档 |
| 每镜抽帧 | **维持 3 帧**。降到 2 帧虽然省 40%，但说话人判定和情绪标注明显变差 |
| 温度 | 维持 0.2。改成 0 没用（一致率只从 55.8% 动到 57.5%，token 反而略增） |
| 标注本身不稳定 | **同参数重跑，一致率只有 55.8%**。这是模型的随机性，不是分辨率问题——别拿「降分辨率毁质量」当结论 |

## 七、工程纪律（v0.2 保留，仍然有效）

1. **出点上限 = 视频流时长**，不是文件 format 时长（每集视频流短 0.6–0.7s）。
2. 切台词边界用**原片硬字幕出现/消失**（±0.3s）。
3. 验证纪律：**抽单帧全尺寸看字幕**；小拼图（<300px 宽）会看串行。
4. 滤镜链：分段 loudnorm 后必须 alimiter；SAR 必须 setsar=1；采样率统一 48k/fltp。
5. 配音时原剧静音（duck），解说停了原声自动恢复；**留白段不许被解说压到**。
6. 解说每段必须在本段画面内结束，超时直接报错。
