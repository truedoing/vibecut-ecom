# 孪生解说 · 方法定义

> 定名 2026-11-08，张老师拍板。英文名 Twin-world Narration。
> 适用范围：短剧 / 剧集推广的 AI 二创解说，跨剧复用的独立解说 IP。

## 定义

**不把旁白贴在片子上，而是用 AI 在原剧旁边「生」出一个同源的世界——一个剧里没有、
却和剧里人活在同一条巷子的角色。她自言自语，或忽然看向镜头跟观众说一句。
她不改剧情，却让剧情多了一层讲述。解说由此从「转述」变成「二创」。**

关键词：**孪生**＝同源、共享世界观、像但不等于，正好对应「相通但不打破」。

## 与传统解说的分别

| | 传统混剪解说 | 孪生解说 |
|---|---|---|
| 解说者在哪 | 画面之外，只有声音 | 画面之内，有自己的身体与场景 |
| 与原剧关系 | 转述、评价、科普 | 同源孪生世界，不干预剧情 |
| 角色体系 | 无 | 新增角色，可跨剧复用成独立 IP |
| 二创证据 | 改写文案 + 配音 + 字幕轴 | 新增叙事层本身，天然可证、抄不走 |
| 观众感受 | 「有人在讲这部剧」 | 「隔壁那个人又在说那家的事」 |
| 生产依赖 | 剪辑 | AI 视频生成（场景扩展、融入式出镜） |

## 三条硬规矩

> ⚠️ **第 3 条「原生与解说交替」已被取代（2026-11-09）**，见文末「补：形态修订 · 电视框」。
> 下面三条原文逐字保留，不删——翻案过程本身就是素材（过程文档制度）。
> 第 1、2 条及本文的「定义 / 跨剧 IP / 是不是独创」仍然有效。

1. **相通但不打破**：同年代、同地域、同一条巷子；不与剧中人同框、不对话、不对视，
   不改动或补写剧情，不出现大结局画面。
2. **只说自己的词**：她可以自言自语，也可以打破第四堵墙对观众说话，
   但绝不说剧中原台词——一旦说了，她就变成剧中人，声音也会串线。
3. **原生与解说交替**：不必每段出镜，出镜段与原生段交替进行，解说可走画外音盖过场。

## 区隔手段（融合越容易，越要做足）

剧与解说者同为 AI 生成，质感天然无缝，**不能靠「真人 vs AI」区分**。

- 视觉：她那侧偏暖、偏旧、带暗角与轻颗粒；剧那侧正常清亮彩色 —— 靠**两个世界的色温差**。
  不用整体去灰：灰色更易被读成「回忆 / 闪回 / 前史」，不是「外人在讲」。
- 身份：固定服饰、固定道具、固定开场动作、固定第一句，四样跨剧不变（小屏认不准脸）。
- 叙事：始终「隔壁」视角，只讲不下判断。

## 是不是独创

四个零件都有先例，但从未装在同一台机器上：

| 已有范式 | 差在哪 |
|---|---|
| 古希腊歌队 / 说书人 | 评论不参与剧情，但它是原剧自带的，不是二创加的，也不跨剧 |
| 打破第四堵墙 | 说话的是原剧角色，不是外来的 |
| 电影解说号 / 吐槽 | 声音在片子外面，人进不了画面世界 |
| 同人把新角色 P 进原剧 | 是恶搞同人，不是可复用、跨剧、接变现链路的解说 IP |

结论：**作为一套可复用、跨剧、独立 IP 化、并挂在推广链路上的生产方法，未见对应范式**。
对外表述用「我把它定义成一套方法」，不用「全球首创」——**定义权比首创权有用**，
尤其是要写文章、做课程、教学生的时候。

## 补：形态修订 · 电视框（2026-11-09，张老师拍板）

**变了什么**：解说不再「交替」，只在开头出现**一次**。结构为
「引（原片高光 ≤3s）→ 框（缩入王婶家电视，王婶一句点题 ≤4s）→ 织（正片全程原声）」。
详见 `docs/电视框三拍_混剪方法论.md`；执行单见 `runs/八零憨妻/D1_第1条/sd_001_v4_电视框执行单.md`。

**为什么翻案**：51.07s 的 8 段交替版实测节奏被解说切碎。短剧 3–5 秒一反转，
信息密度已到极限，中段解说只能盖住原声或压低原声，且观众每几秒就得从「沉浸剧情」
切到「听人评议」再切回来。张老师原话：「这种中间加解说的模式可能不适合短剧」。
解说的职能因此从**补信息**改成**装一副眼镜**——告诉观众用哪个看法看，装一次就够。

**这一改反而让孪生更像孪生**：

| 原做法 | 电视框做法 |
|---|---|
| 靠色温差 + 四项识别特征**全片维护**两个世界的边界 | **一次缩放动作**划完边界：剧被冻结、缩小、装进屏幕，变成「被观看的物件」 |
| 三条硬规矩 + 持续区隔，穿帮面遍布全片 | 塌缩成一条：**她只在电视外说话**。她本来就不在剧情里，吐槽 / 看观众 / 换台都不算打破 |
| 隐喻是舞台幕布（王婶在**介绍**） | 隐喻是老电视（街坊跟我们一起**观看**） |

「相通但不打破」没有作废，是被**物理化**了：从一条要全程盯着的纪律，变成一个一次做完的动作。

**仍然有效的**：本文的「定义」「与传统解说的分别」「只说自己的词 / 绝不说剧中原台词」
「跨剧独立 IP」「是不是独创」全部不变。变的只是**解说出现的次数与位置**，不是它是什么。

**已作废的**：第 3 条「原生与解说交替」；「区隔手段」里全片维护色温差的做法
（框拍内部仍保留偏暖偏旧带暗角的屋内色调，但不再需要延伸到正片）。
