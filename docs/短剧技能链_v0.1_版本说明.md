## 二、v0.1 已验证的能力（及格线证据）

1. **电视框三拍结构成立**：引（原剧高光钩子）→ 框（AI 王婶破墙点评）→ 织（跨集蒙太奇顺叙轴）。
2. **AI 钩子可控**：破墙表演两拍（看屏怒其不争→转头对观众数落）验收达成；台词一字不差。
3. **形象一致性可用**：场景图 + 服装图 + 音色锚（+固定 seed）跨片保持同一王婶。
4. **成本结构摸清**：10s/480p ≈ 100858 tokens ≈ 2 元；480p 为原则（1080p token 反涨 2.4 倍）。
5. **混剪工程链可用**：真实秒数选段、字幕消失定切点、xfade 叠化接 AI 段、分段 loudnorm + alimiter。

## 三、v0.1 的硬边界（实测踩出来的，写进提示词/技能前必读）

1. **真人审核墙**：参考图含真人（含 AI 生成的脸锚帧）一律 400 拒，不扣费。可用的是无脸场景图/服装图。
2. **首尾帧封闭模式**：用了 first/last_frame 就不能带任何参考图/音频，且输入图不能有真人 → 实测不可用于「剧画面↔AI 世界」衔接，改走 B 案（叠化）。
3. **AI 写字与 seed 强相关**：「王婶看剧」seed 20261108 写成「三婶」，换 20261109 即对。要写字的镜头，换 seed 重抽优先于后期贴图。
4. **480p 9:16 实际输出 496×864**，与 1080×1920 / 720×1280 混剪需显式统一分辨率。
5. **分段 loudnorm 的片子最终必须加限幅器**（叠化交叉区叠加超峰，v8 实测 TP +1.24dB 削波）。
6. **收尾切点必须看末帧画面**，不能只对台词时长（钩子 v3 第一次切进婆婆反应镜头的教训）。

## 四、0.2 待办（张老师已点名或实测留痕）

- 电视屏幕里的画面要**动起来**（像电视在演，而非静态/微动）——首选项。
- AI 段环境声：狗叫写了但未出现；开头「哼哼」杂音待人耳定去留。
- 短剧专属 mix 技能化（现在装配逻辑散在 run 级脚本 mix_v7/v8/v9_overall.py）。
- 台账「演到哪」按 stages 数组位置取值，新旧形态共存时会显示错（修法候选：按 at 时间取最新 approved）。
- `prompt_lint` W6 带货硬编码误报待按行业参数化。
