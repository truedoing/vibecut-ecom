# 两周执行计划：短剧练手 × 带货窄口验证

> 起止：2026-11-07（周六）～ 2026-11-20（周五）
> 时间预算：每周 6–8 小时，从每周 20 小时里切，不占教学主线
> 总目标：**不是赚钱，是拿到三组干净数据**——①钩子点击率 ②带货完播/点击 ③选品判断的第一手体感

---

## 〇、开工前必须记住的四条

1. **所有授权、入口、任务全部免费。** 任何"一级授权费 / 高佣开通费 / 培训费"都是骗局。
2. **短剧只用任务页官方素材，必须从任务页点「去发布 / 参与投稿」。** 直接点加号发的视频不挂组件 = 白干。
3. **带货的效果对比段必须实拍。** AI 生成不出真实清洁效果，硬做就是虚假宣传。
4. **只记录，不中途改策略。** 两周内数据没看够之前，不换品类、不换平台、不改人设。

## 一、第一周（11/7–11/13）：开户 + 短剧 6 条 + 定品类

### D1 · 周六 11/7 —— 开户日（约 1.5h）

- [ ] 快手搜「星火计划」→ 进任务广场 → 筛「短剧」→ 确认能领任务
- [ ] 创作者中心 → 更多服务 → 磁力聚星 → 提交开通申请（1000 粉够格，先拿权限不主攻）
- [ ] 创作者中心 → 找「带货 / 精选联盟」→ 确认短视频挂小黄车权限状态（1000 粉应已解锁）
- [ ] **记录三个后台的真实门槛、结算规则截图**（入档素材）
- [ ] 快手建独立小号人设确认：「一个 48 岁男老师的家用好物」（如已建则跳过）

### D2 · 周日 11/8 —— 选剧 + 选品（约 2h）

- [ ] 星火任务广场按「广告分成（IAA）」筛 3 部剧：家庭恩怨 / 婆媳 / 错嫁逆袭 / 年代题材优先
- [ ] 下载素材（只下前 3–5 集高能片段）
- [ ] 带货品类候选：列 5 个，按四维打分（每项 1–5 分）
  - 客单价 30–100 元（日常不犹豫）
  - 佣金率 ≥ 30%
  - 有肉眼可见的前后对比 / 明确使用场景
  - 1688 / 精选联盟货源好找
- [ ] 定 1 个品类，选 3 个具体商品，找到货源链接

### D3 · 周一 11/9 —— 下样品 + 写脚本（约 1.5h）

- [ ] 3 个样品全部下单（预算 ≤300 元）
- [ ] 写 2 条短剧推广脚本（固定结构：前 3 秒冲突高光 → 关键情节 → 悬念截断 → 引导点组件）
- [ ] 用自己产线（LLM 出稿 → 改 → 配音），**记录 AI 在哪步省了时间**（教学素材）

### D4 · 周二 11/10 —— 短剧 2 条（约 1.5h）

- [ ] 剪 2 条（30–70 秒，字幕 + BGM + 封面大字，做去重：变速 / 缩放 / 调顺序）
- [ ] 从任务页「去发布」上传，**发布前确认左下角有组件**
- [ ] 固定时段发布：19:00–22:00

### D5 · 周三 11/11 —— 短剧 2 条 + 带货脚本（约 1.5h）

- [ ] 剪 2 条短剧，任务页发布
- [ ] 写 2 条带货脚本（固定四段：3 秒冲突 → 商品入戏 → 效果对比 → 挂车引导）
- [ ] 每条脚本只预设 1 个变量（本周先全部用同一结构，下周才做 A/B）

### D6 · 周四 11/12 —— 短剧 2 条 + 收样（约 1.5h）

- [ ] 剪 2 条短剧，任务页发布（本周累计 6 条）
- [ ] 样品到货验收：质量能不能过自己这关？过不了立刻换，不硬推

### D7 · 周五 11/13 —— 第一周复盘（约 45 分钟）

- [ ] 填数据表（见第三节）
- [ ] 只回答一个问题：**6 条的组件点击率分布是怎样的？**

## 四、判读分叉表（D7 和 D14 各用一次）

| 现象 | 诊断 | 动作 |
|---|---|---|
| 短剧播放长期 <500 | 新号冷启动，正常 | 继续发满 9 条再判断 |
| 播放正常，组件点击率 <1% | 钩子问题 | 换开场结构（冲突前置 / 悬念提问 / 反差），一次只换一个变量 |
| 组件点击率 1–3% | 及格 | 该结构固定下来，加量 |
| 组件点击率 >3% | 钩子能力成立 | **这是可迁移能力，写进教学素材**；考虑上磁力聚星找同类高佣剧 |
| 带货完播率 <20% | 前三秒不行 | 改开场，不动商品 |
| 完播 >30%，点击率低 | 货不对 / 挂车引导弱 | 换品或改引导话术 |
| 点击高但不出单 | 商品页 / 价格 / 评价问题 | 换品，不怪视频 |
| 两周 0 成交且点击率 <1% | 内容生产层问题 | 回到脚本基本功，不换渠道 |

## 五、止损线（写给两周后犹豫的自己）

- **短剧线**：9 条发完，点击率全部 <1% → 结论是"钩子还需练"，短剧线暂停，方法带回带货线。**不再找第六个渠道。**
- **带货线**：6 条发完，完播率全部 <20% → 问题在前三秒，回炉脚本，**品类不动**。
- 任何一条线出现"数据在涨"，第三周只做一件事：**把涨的那条线加量**，另一条降为每周 1 条。
