# 去重技能 技术方案 v0.1

> 2026-11-14 建。张老师定题：去重这块单独给一份技能的技术设计，只管去重技能，修饰技能另算。
>
> 建题经过（留档，翻案不删原文）：11-14 上午先按「文案原则 + 自动化技能」两分讨论；随后张老师把自动化那半再拆成两个可选技能——**去重技能**（应对平台查重）和**修饰技能**（图层上写文字，锦上添花）；文案编排那边只留一处约束优化。技能形态在三选一里定了 **B：独立技能、不占流水线工位**。
>
> 硬规矩（张老师 11-14）：**去重的权重小于剪辑质量。** 加约束、挂技能之后，叙事质量不许下降。本方案把这条落成两条工程约束：技能挂在清单人审之后、只动画面不碰清单；默认参数保守、不遮挡人物。
>
> 验证剧改成「以真心守护至亲」（不再用八零憨妻）。文案侧零误伤测试用 D3，画面基线用 D1。

## 一、管什么、不管什么

| 管 | 不管 |
|---|---|
| A1 画中画 + 模糊背景 + 缩放边框 | A4 图层文字（人物关系、章节、花字、片头尾）——归**修饰技能** |
| A2 分屏 / 多屏错开 | B1 片段长度、B2 全片时长、B4 切点错开、B5 跨集倒插——归**文案编排** |
| A3 全片画面参数包（裁切、亮度、暗角、噪点） | 配乐、字幕重铺、片头尾重做——**音频一律不做**（零解说纯剪靠原片台词讲故事，静音等于删内容） |
| 原剧硬字幕清除（挂在 A1 里顺带做） | 不改段序、不改选段、不改五幕、不改台词、不改清单任何一个字段 |
| 给装配器一份可挂的画面处理参数 | 不自己拼成片、不做二次编码 |

一句话：**这个技能只做「准备」，装配器负责「挂上去」。**

## 二、它长在哪

**独立技能目录，不占流水线工位**（B 方案）。

- 新建 `skills/short-drama-dedup/`，含 `SKILL.md` + `scripts/` + `config/`
- 登记点只有四处：`check_env.py` 的 `SKILLS` 加一项、手工建软链到 `~/.workbuddy/skills/`、文档里「8 个技能」改 9、重开会话
- **不动**：`status_overview.py` 的 `STAGES`、状态模板的 `artifacts`、门禁 G0–G3、主管入口表、工作台、存量所有 `状态.json`。这正是 B 比 A 省事的地方——A 会让存量片子从「5/5 完成」变成「5/6」，刚验收的东西整套重验
- 首段照项目规矩写「本技能不是入口，调度走 `short-drama-supervisor`」

**一个矛盾要先定**：B 的定位是「可选挂」，可去重其实是每条片子都要。挂成纯可选容易漏。定法是——技能是独立目录、不占工位，但**由主管在装配时默认调一次**，状态台账顶层加一个字段 `dedup_profile` 记「这条片子用了哪套参数、哪个技能版本」。不漏挂，也不动七环节。

## 三、输入 / 输出契约

| 项 | 内容 |
|---|---|
| 输入① | `plan.json`（只读，取每段的 `type` / `ep` / `a` / `b` / `w` / `h` / `fps`） |
| 输入② | 原片素材目录（只读，用于首帧实测字幕位置、抽对照截图） |
| 输入③ | 账号级视觉参数配置（放大比例、字幕带高度、模糊强度、边框、亮度偏移），写一次，不是每条片子写 |
| 输出① | `runs/<剧>/<任务>/dedup_spec.json`：全片参数 + 逐段参数，**只描述怎么改画面，不含任何剪辑决策** |
| 输出② | 若干 PNG 遮罩（圆角、动态边框、纯色/渐变底），可选 |
| 装配器接口 | `mix_trailer.py --dedup <spec.json>`。不给这个开关就完全不挂，行为跟现在一模一样 |

**为什么不让技能自己出成片**：那样得对已拼好的 mp4 再跑一遍 ffmpeg，多压一次、画质掉一档。交给装配器在组滤镜图时挂，全程只编码一次。

## 五、画面处理链接在哪（核心）

### 5.1 装配器现状

`mix_trailer.py` 是**逐段各建一条滤镜链 → 一次 concat → 一次 ffmpeg 输出**，没有第二遍编码。ep 段当前是：

```
[i:v]trim=start=a:end=b,setpts=PTS-STARTPTS,
scale=W:H:force_original_aspect_ratio=increase,crop=W:H,
setsar=1,fps=FPS,format=yuv420p[vi]
```

`video` 段同构；`black` / `card` 段只有 `scale/setsar/fps/format`；最后 `[vcat]concat` → `-map "[vcat]"`。

### 5.2 改动点（四处，都在装配器）

1. `argparse` 加 `--dedup`，默认 `None`
2. 读到 spec 后，把 ep / video 段那条视频链替换成 `dedup_ep_chain()` 生成的串（见下）
3. `black` / `card` 段套同一套**外框**（背景 + 边框），否则片中黑场和字幕卡会突然「跳」一下
4. `[vcat]` 之后插一条全局参数包，输出 `[vout]`，`-map "[vcat]"` 改成 `-map "[vout]"`。`durations` 和 `-t total` **不动**

### 5.3 ep 段新链（示意，实现时按 ffmpeg 版本校准）

```
[i:v]trim=a:b,setpts=PTS-STARTPTS,split=2[bg][fg]

[bg]crop=W:H-字幕带,scale=W:H,boxblur=20:2,eq=brightness=-0.06[bg2]
[fg]crop=W:H-字幕带,scale=W*0.90:H*0.90,
    scale=W:H:force_original_aspect_ratio=increase,crop=W:H,
    setsar=1,fps=FPS,format=yuv420p[fg2]

[bg2][fg2]overlay=(W-w)/2:(H-h)/2[vi]
```

圆角/边框用生成的 PNG 走 `format=rgba` + `alphamerge` 叠，或直接用 `geq` 做 alpha。**所有段输出必须同尺寸、同 fps、同 pix_fmt**，否则 concat 直接失败——这是这类改动最常见的翻车点。

### 5.4 硬字幕怎么清（张老师提的疑问，不用单独做一步）

正确顺序是 **先裁掉字幕带 → 再缩小主画面 → 再叠背景**。字幕直接出画，干净、不糊、全自动，A1 本来就要缩放，不加工序。

- 首选：`crop` 掉底部字幕带（一般 10–15%，按剧实测），再放大回原尺寸
- 备选：`delogo=x:y:w:h`，能自动但留模糊痕迹
- **不建议**蒙版色块 / 局部模糊盖字幕：巨量星图公告把「局部模糊处理」明文算作简单加工，两头不讨好

三个复核点：① 放大裁切会切掉画面边缘，人物构图要过一眼 ② 字幕若在顶部或中间，裁切方向要做成配置项 ③ **模糊底层不能直接用带字幕的同一段原片**（会留字影），底层建议纯色 / 渐变 / 暗化，或同样先裁

### 5.5 全局参数包

```
[vcat]crop=W-16:H-16:8:8,scale=W:H,
eq=brightness=0.03:contrast=1.03,vignette,noise=alls=3:allf=t[vout]
```

- `crop` 8px 起就能改画面指纹；`eq` 亮度 +3%~+5% 改掉一批评判比特
- **不做 `hue` 色调偏移**（灰度化时颜色就被扔了，无效）；不做换码率 / 重新压制（只改文件指纹，画面结构没动）
- 这套参数对指纹有实际作用，但它是**顺手的效果，别当命门**。真正改变画面格局的是 A1/A2

## 六、参数从哪来、怎么记

| 层级 | 放哪 | 谁写 |
|---|---|---|
| 账号 / 剧级审美参数 | `skills/short-drama-dedup/config/视觉参数_默认.json`（放大比例、字幕带高度、模糊强度、边框、配色、字体路径） | 写一次，首次用「以真心守护至亲」实测校准后定稿 |
| 每条片子的参数快照 | `runs/<剧>/<任务>/dedup_spec.json` | 技能自动生成，人不用填 |
| 挂没挂、挂了哪套 | `状态.json` 顶层 `dedup_profile` | 主管写一行，不进 `artifacts`、不参与依赖作废链 |

**建议默认参数**（未实测，标为待校准）：主画面缩放 0.90（区间 0.86–0.92）、底部字幕带 12%、模糊 `boxblur=20:2`、亮度 +3%、裁切 8px。首次拿 D1 的原始帧跑一遍，看字幕清没清干净、边缘有没有切到人物，再定死。

**一个必须守住的红线**：主画面缩放不许低于 0.85、图层不许压到人物脸部区域。这两个值不是去重参数，是「不许伤叙事」的护栏，写进配置校验里，越界直接报错，不给人调。

## 八、已知带伤与边界

1. **没在真实素材上跑过**。以上全是公开资料 + 装配器代码结构推出来的设计，不是自有验证数据
2. **合规矛盾**：巨量星图公告把「仅添加水印/文字、更换滤镜、局部模糊」定性为简单加工。A3 的调色在这一类边缘，用之前心里有数；重心放 A1/A2 改画面格局，不靠调色

5. **音频不做**是主动取舍，不是遗漏：零解说纯剪不能静原声，配乐仍按老规矩在剪映人工加
6. **变速 v0.1 不做**：会撞时长账和台词节奏，按「去重让位剪辑质量」砍掉
7. 前几轮讨论里「原创帧占比 25–30%」「最长连续不超 10 秒」这些无出处说法**已撤回，不进本方案**

### 10.3 最大的一个翻案：不能用「几个人说话」判吵架

第一版判据是这么想的：静场/独白 = 一个人说、话少；吵架段 = 多人抢话。
写出来跑《以真心守护至亲》D3，挑 6 段，**跟 11-14 人工挑的 5 段只重合 1 段**。

逐句看人工那 5 段才发现问题：

| 段 | 说话人 | 景别 | 人工选它 |
|---|---|---|---|
| S04_那道疤 | 2 人（「挡」那句没标人） | 近景→特写 | ✓ |
| S07_拿穷样子试他们的心 | 2 人 | 近景×3 + 中景 | ✓ |
| S14_我先带妈妈回家 | 2 人 | 中景×3 + 近景×6 | ✓ |
| S20_是我今天才看清 | 2 人 | 中景 + 近景×3 | ✓ |
| S21_他根本没把这些当回事 | 2 人 | 全近景 | ✓ |

**五段里有四段是「两个人在说」**，全被第一版判成「吵架段」排除了。
错的不是阈值，是维度：**抢话的特征是句间空隙小，不是人多。**

改成三个维度后（景别占比 × 3 + 句间中位间隔 + 语速），D3 挑出的 6 段命中人工 3 段。

### 10.4 第二个翻案：机器判不出「该强调哪段」，别装懂

改完判据还是对不上，继续查。把 22 段的近景占比排一遍：
**近景 100% 的有 5 段，人工只挑了 2 段**（S04、S21），S15／S13／S03 都没选。

那三段是「她不嫁我嫁」「这婚我不结了」「保安把她弄出去」——镜头贴着人脸，
但叙事上是动作或宣言，不是情绪落点。**这是内容判断，不是机器能打的勾。**

于是定了口径，写进 `SKILL.md` 和代码注释：

> 机器只判「**套了会不会伤画面**」，判不出「叙事上最该强调哪一段」。

判据分三步：先硬排会伤的（段 < 3 秒、近景 < 50%、段 > 28 秒），再按画面语言排序取前几段，
最后 **人不对就用 `--a1` 自己圈，这是正规路径不是补丁**。

不拿人工答案去调阈值——那是过拟合，换部剧就废。
