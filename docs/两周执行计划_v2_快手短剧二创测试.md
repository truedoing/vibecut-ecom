## 一、四条铁律（v1 三条 + 新增三条）

1. **所有授权、入口、任务全部免费。** 任何「一级授权费 / 高佣开通费 / 培训费」都是骗局。
2. **必须从任务页点「去发布」。** 直接点加号发的视频不挂组件 = 白干。
3. **只用任务内官方素材；AI 生成画面不得冒充剧中情节。** 判据一句话：AI 画面服务「氛围、物件、场景」可以，服务「这个人物还发生了什么」不行 —— 后者会被用户判货不对板，直接触发平台打压（官方规则：投诉率高的剧，相关短视频限流）。
4. **两周内只记录、不改策略。** 数据没看够之前不换品类、不换赛道、不改人设。
5. **AI 生成内容必须标识。** 发布页有对应选项，别漏。
6. **带货的效果对比必须实拍。** AI 只做场景和氛围，不能做前后对比。

## 四、选剧标准（D2 用，每项都要记）

**领任务前 30 秒检查（顺序别反，11-07 实盘补）**：

1. **先点素材链接**，能打开、能下载再往下走 —— 踩坑实录：《明月曾照彩云归》任务截止 2028-12-31，
   但网盘/片单素材链接已过期，任务页完全看不出来。**任务有效期 ≠ 链接有效期**。
   链接打不开就立刻换剧，别在这部上耗时间。
2. 看 **投稿作品数**（<5 万优先）
3. 展开「任务介绍」+「必须完成以下要求」（指定片段、时长、字幕规范，漏了驳回）
4. 点「点击试看」确认是实拍
5. 看结算说明的计费口径（按站内观看广告结算 = IAA，数据最干净）

**先看一个数（比收益数字有用得多）**：

| 字段 | 判据 | 理由 |
|---|---|---|
| **投稿作品数** | **越少越好，优先 <5 万** | 竞争密度的直接读数。30 万条说明这剧已被剪烂，同质化限流 + 新号分不到流量 |
| **奖池剩余比例** | **只看「任务新旧」，不单独用于选剧** | 11-08 实盘：本剧 90.8%，推翻 11-07「20% 是伪指标」的判断 —— 它是真实剩余值，前两部老剧恰好都消耗到 20% 才看起来一样。与投稿数互证即可 |

**筛选条件**：

- 任务类型：**效果计费 / 广告分成**优先（点组件看广告即产生收益，不依赖用户充值，数据更干净）
- 题材：**A 类女频家庭伦理**（婆媳 / 婚姻 / 遗产 / 远嫁 / 赡养）优先；允许退到 D 类年代亲情、家庭纠纷
- **写实人像剧**；点「点击试看」确认是实拍，避开 AI 仿真人剧与漫剧（素材本身若 AI 生成，会削弱 AI 叙述者的差异感）
- ~~上线 7 天内~~ → **降级为加分项，不作硬条件**（11-07 实盘：按「最新发布」翻查，在架任务里凑不齐「7 天内 + 家庭伦理」）

**4 项官方指标**（任务详情页可直接看，逐项记数）：

| 指标 | 判据 |
|---|---|
| 前 3 集留存 | 越高越好，这是剧本身的钩子强度 |
| 退款率 | 越低越好（退款会扣回佣金） |
| 投诉率 | 越低越好（高的会被平台打压，连带你的视频限流） |
| 小程序点击率 | 参考值，判断剧的转化底子 |

**别按佣金率选剧** —— 官方明确提示：高佣常配高退款、高投诉。
**素材包要看两件事**：可拆段数（决定你能出几条）、开场画面质量（原剧前 3 秒是平淡对话 → AI 引子有空间；已经是高能冲突 → 引子反而占时长）。

## 五、AI 层规范（W1 档 1：王婶背影 + 画外音）

**角色卡**

- 55–60 岁女性，北方口音，素色棉布外套、深色裤子、头发盘起
- 场景：北方老院子 / 楼门口 / 菜市场
- 身份设定：隔壁邻居，住了三十年，什么都看在眼里（叙述者，**不是**剧情参与者）

**5 个基础镜头（生成一次，全程循环用）**

1. 背影晒被子
2. 背影在水池边洗菜
3. 侧脸望向远处
4. 手部择菜特写
5. 转身推门进屋

每条视频取 1 个开场 + 1 个收尾，其余全部用原剧素材。

**声音**：AI 配音，45–55 岁女声，语速 3.8–4.2 字/秒（中老年舒适区）。

**开场白模板（3 套，各 3–5 秒）**

1. 关系型（默认）：「这院子我住了三十年，隔壁那家的事，我最有数。」
2. 悬念型：「那天楼下吵起来的时候，我就知道这家要出事。」
3. 结论型：「都说这媳妇不孝顺，可我在旁边看着，不是那样。」

**收尾模板（2 套）**

1. 「后面的事还没讲完，点下面自己看。」
2. 「这家人后来怎么样，你往下点就知道了。」

**单条结构（60–70 秒）**

```
0–3s   王婶开场（画外音 + 背影）
3–8s   原剧第一个冲突点（挑最狠的那句台词）
8–45s  原剧推进 + AI 解说词
45–58s 悬念截断（停在关键动作前）
58–65s 王婶收尾 + 引导点组件
全程    右上角角标「家长里短 第N期」
```

**三条红线**

1. **别让正面人物说话却不开口。** 用背面、侧脸、手部、转身躲开嘴部 —— 正面说话不开口就是「假」。
2. **AI 生成必须标识。**
3. **别用像真人的脸**，尤其别撞明星、网红。虚构人物，越素越好。

**W2 才考虑升级**：再叙事空镜（解说讲到「三十年前那个冬天」时插 AI 生成的年代镜头）。它要插在故事中间，一条视频补 3–5 段、每段生成 2–3 次，时间是档 1 的 5 倍，W1 上它产能必崩。

### 选段工序：不看完剧，也能剪出钩子（11-07 定）

平台详情页是**运营后台**，给的是结算规则和素材包，不是剧情简介 —— 这不是缺陷。
你做的不是剧评，是**引流切片**：只需要「高能冲突点 → 2–3 段递进 → 悬念截断 → 引导点击」，
要的是**片段级信息**，不是整部剧情。

1. **先展开详情全文**：「任务介绍」右侧「展开」+「必须完成以下要求」必须看完（指定片段、时长、
   字幕规范都在这里，漏了会驳回）；结算说明里常带**片单文档链接**（腾讯文档 / 网盘），
   那里面往往有集数和剧情梗概，比在 App 里翻快得多。
2. **素材包抽帧扫读**：不逐集看，每段拖到 1/4、1/2、3/4 处各看一帧；只找吵架、当众揭穿、
   摔东西、对峙这类高冲突画面 —— 静帧就能认出来。
3. **ASR 转写 → LLM 提炼**（本项目的核心工序，也是「AI + 混剪」真正要测的产能）：
   把片段台词转成文本，喂给模型输出「人物关系 / 本段冲突 / 高能台词 Top5 / 可截断点 / 3 个开场白」。
   **全程不用看画面**，直接得到钩子素材。
4. **只看前 3 集建立人物关系**。类型片套路固定（远嫁 = 婆家刁难 + 娘家不理解 + 丈夫不作为 +
   反转），看完前 3 集够用，后面是同一套路的变体。
5. **别看结局**。官方规则明确：放出大结局画面会降低付费意愿、易判低质二创。
   而且不知道结局的人，悬念才写得真。

> 反直觉的一点：**没有简介反而是好事**。平台若给了统一简介，所有达人会写出同一套解说词，
> 直接撞同质化限流。信息不对称正是 AI 转写这套流程的壁垒所在。

## 六、W1 排期（11/7–11/13）：账号改造 + 短剧 6 条

| 日 | 任务 | 时长 |
|---|---|---|
| D1 六 | 老号爆改六步（第三节） | 1.5h |
| D2 日 | 按第四节筛剧、领素材；带货品类四维打分（客单 30–100 / 佣金≥30% / 有肉眼对比 / 货源好找），定 1 品、选 3 个商品、**下单 1 个样品** | 1.5h |
| D3 一 | 写 2 套解说脚本（开场白 + 解说词 + 截断点）；生成王婶 5 个基础镜头 + 配音 | 1.5h |
| D4 二 | **一次批量剪 4 条**（第 1–2 条用最稳结构打底，第 3–4 条换钩子），发 1 条 | 2.0h |
| D5 三 | 发 2 条（19:00–22:00） | 0.3h |
| D6 四 | 发 1 条；样品到货验收（过不了自己这关立刻换，不硬推） | 0.5h |
| D7 五 | 填数据表；只回答一个问题：**6 条的组件点击率分布是怎样的？**；写 3–5 句复盘（含当时的判断和情绪） | 0.7h |

**为什么前 2 条不做实验**：账号刚改标签，前两条数据崩了会拖累后续推荐权重。先用能跑的模板把账号热起来，第 3 条起再换钩子。

**W1 三个钩子结构**（同剧同片段，只换前 3 秒 + 解说词）：

- **冲突前置**：开场白直接抛矛盾（「婆婆把碗摔在她脚边」）
- **悬念提问**：开场白抛问题（「这家为什么半夜总亮着灯？」）
- **反差揭示**：开场白先立印象再反转（「都说她贤惠，直到那天…」）

## 九、判读分叉表（D7 和 D14 各用一次）

| 现象 | 诊断 | 动作 |
|---|---|---|
| 短剧播放长期 <500 | 新标签冷启动，正常 | 继续发满 9 条再判断 |
| 播放正常，组件点击率 <1% | 钩子问题 | 换开场结构，一次只换一个变量 |
| 组件点击率 1–3% | 及格 | 该结构固定，加量 |
| 组件点击率 >3% | **钩子能力成立，这是可迁移能力** | 写进教学素材；考虑上磁力聚星找同类高佣剧 |

| 完播 >30%，点击率低 | 货不对 / 挂车引导弱 | 换品或改引导话术 |

| 两周 0 成交且点击率 <1% | 内容生产层问题 | 回脚本基本功，不换渠道 |

## 十、止损线（写给两周后犹豫的自己）

- **短剧线**：9 条发完，点击率全部 <1% → 结论是「钩子还需练」，短剧线暂停，方法带回带货线。**不再找第六个渠道。**
- **AI 层**：W2 实验证明无增益 → 保留开场收尾（成本低、有识别度），砍掉空镜补拍，别为了「用 AI 而用 AI」。
- **带货线**：3 条发完，完播率全部 <20% → 问题在前三秒，回炉脚本，**品类不动**。
- 任何一条线出现「数据在涨」，第三周只做一件事：**把涨的那条线加量**。

## 附：AI 生成与合规边界（备忘）

- **可以**：AI 生成氛围/物件/场景/虚拟叙述者；AI 配音；AI 修复画质；AI 处理字幕；AI 封面外扩
- **有条件**：解说讲到剧外时空时插示意图（必须抽象、无脸、不指涉具体剧情）
- **不行**：AI 生成剧中人物不存在的情节（货不对板 → 投诉 → 限流）；用剧照做图生视频（输出近似画面，可能被判搬运/侵权）；跨平台分发星火素材（授权仅限快手该任务内）
- **AI 生成的画面版权属于你**（用有商用授权的模型），但**混入网上找的影视素材会侵权**
