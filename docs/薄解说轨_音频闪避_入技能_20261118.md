# 把「音频闪避解说」固化进技能（2026-11-18）

## 背景

前面几个案例（八零憨妻 D6、《以真心守护至亲》D3/D5/线二）里，解说叠音都是我每次手打
ffmpeg 命令完成的：edge-tts 生成配音 → `volume='if(between(t,a,b),0.15,1)'` 压低原声 →
`adelay` 对齐 → `amix` 混合。命令一长，换个会话就丢，而且手算解说时长最容易错。
张老师要求把这套做法更新进技能。

## 决定：独立一步，不动装配器

- **不动 `mix_trailer.py`**：它的音频链（loudnorm/alimiter）不能乱碰；解说是在成片出来
  之后加的一层薄壳，独立一步，出问题只重做这一步，不重拼画面、不动清单。
- **装配技能（`short-drama-trailer`）** 收执行：新增 `scripts/duck_narration.py` +
  `references/解说轨_音频闪避.md`，SKILL.md 工序加第 5 步（可选）。
- **编排技能（`short-drama-script`）** 收文案决策：改 description 边界，加"薄解说形态"
  说明和改动影响一行。文案归编排、配音叠音归装配，职责不混。

## 脚本能力

输入：已装配成片 + 若干解说段（现成音频或文案）。输出：带解说成片，画面不动。

- 自动探测每段解说时长，算出该压原声的区间（以前手算最容易错的地方）
- 文案可直接喂，脚本调 edge-tts 生成（免费、不用密钥），音频落在成片旁 `解说音频/`
- `--dry` 只读预览，不生成任何文件
- 重叠、超出片尾、输出覆盖原片都报错误、退出码 2、不出片
- 默认音色 5 号云健，压低到 0.15 倍，解说音量 1.25 倍，都可改

## 验证记录

| 测试 | 结果 |
|---|---|
| `--dry` 预览 | 时长/区间与手搓版一致（7.75s、3.67s），没生成文件 |
| 正式出片（现成音频两段） | 144.9s / 1080×1920，与手搓版几乎字节级一致；音量包络同为 −17.5dB → −24.3dB |
| 文案自动配音路径 | edge-tts 生成成功，音频落 `解说音频/13_93_第1段.mp3` |
| 两段解说重叠 | 报错、退出码 2、不出片 |
| 解说超出片尾 | 报错、退出码 2、不出片 |
| 同步安装位副本 | 四处文件 md5 一致；自检 14 项全过，版本机制未受影响 |

## 边界（如实记）

- 同步只到本机安装位和仓库；**没重新打专家包、没动资产库**（写资产库要张老师点头）。
  从资产库重新下原始 0.5 包装，这两个技能改动会丢。要不要发 0.6.0 待定。
- 本会话读的是启动时的人格，但技能文件是运行时按路径读的，新脚本当前会话即可用。
- 验证没做语音转文字逐字比对（耗时，张老师明确不耐烦）；落点靠抽帧、声音靠音量包络。
