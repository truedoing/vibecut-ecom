## 二、v0.5 到底改了什么

按包里安装说明，一句话：**以前只管「让观众看懂」，这次补「看完记不记得」**。落到代码上是五块：

1. **结尾收束方法**（方法层）
   - 结尾必须有两个落点：情绪落点（停在有反应的那张脸）+ 信息落点（拿到确凿铁证）。
     两个都没有不算收完。原人审意见是「结束得突然，悬念没留够」。
   - 三档收尾交人圈：露反转钩子（推荐）／完整翻案／不碰反转只收节奏。
   - 反转只露钩子不展开；点睛句用留白，不点破结论。

2. **段间转场**（`mix_trailer.py` + `script/SKILL.md`）
   - 段上写 `"out"` 字段：`cut`（缺省，硬切，行为不变）／`black`（淡出→0.45s 黑→淡入）／
     `card`（1.2s 黑底两行字，报剧名 + 悬念句）。
   - 决策规则写进清单技能：**先顺切点，再判要不要转场**。切点被台词腰斩时先改 `b`，
     加黑场掩盖不了半句被削掉。

3. **叙事打磨法**（新增 `script/references/叙事打磨_冷读到定稿.md`，244 行）
   - 冷读测试找断点 → 三张底表（人物／时间线／观众断点）→ 断点驱动幕结构 → 删繁。
   - 来源是 T1《她是怎么被逼坠海的》六轮人审。

4. **并行装配与提速**（`mix_trailer.py`）
   - `--jobs N` 分块并行；实测本机（16 vCPU 无 AVX2）并行只涨 15% 吞吐，
     **真正的提速是 `--preset veryfast`（2.1 倍）**。
   - `_ffp()` 修 Windows 路径冒号/反斜杠转义。

5. **两笔修账**
   - `make_ass.py` 补 `--opening` / `--quotes-file`（以前缓存快照漏了这两个参数，出片要特意挑版本）。
   - 5 个技能的 `_env.py` 改 ffmpeg 查找顺序：**数据目录 `bin/` 优先于宿主包 `bin/`**
     （防老包自带 4.1 挡住新版）。

## 四、两个坑（下次别再踩）

### 坑一：直接「清空旧目录 + 复制新内容」，中途被打断就成了残缺状态

第一次装的时候，脚本先删旧目录再逐文件复制，会话在复制中途被中断，
结果插件目录只剩 74 个文件，`.codebuddy-plugin/`、`agents/` 都没了——
插件处于既不能用、也看不出坏在哪的状态。

**改法**：先在暂存目录（`plugin-backup/_stage_v0.5/`）把完整内容拼好、校验通过
（版本号 + 10 个技能目录 + 6 个关键文件都在），再 `rmtree` 旧目录、`move` 暂存目录到位。
中途打断最多留个没用的暂存目录，不影响现役插件。

### 坑二：`marketplace.json` 的 `plugins[]` 被清空

装完后 `~/.workbuddy/plugins/marketplaces/my-experts/.codebuddy-plugin/marketplace.json`
里 `plugins` 是空数组（文件标着 auto-generated）。`experts.json` 里登记还在，
所以专家能选中，但登记三件套缺了一件。

按其他 marketplace 的格式补回：
`{"name","description","version","source":"./plugins/<专家名>"}`。

### 附带一条：包里文本是 CRLF

包里 `.py/.md/.json` 全是 Windows 换行。同步进仓库前统一转 LF，
否则 `git diff` 会显示每个文件全文改动，真正的差异全被埋掉。
（这次真实差异只有 651 增 99 删，转 LF 前 diff 是「整个文件都变了」。）

## 五、跟 11-17 上午「钩子与正片之间的边界」的关系

11-17 上午在试「钩子播完、正片开始」怎么让观众分得清，做了几条对比小样
（定格一拍／片花调色／合成冲击音）。当时不知道 v0.5 已经把这个做进装配器了。

**现在的关系是**：

- v0.5 给的方案是 `black`（前段尾淡出 → 0.45s 纯黑 → 后段淡入）和 `card`（报剧名）。
  这是「硬分章」，最明确，实测已通过。
- 上午试的「定格一拍」和「片花调色（降饱和发冷）」**包里没有**，`out` 只认 cut/black/card。
- 两者不是替代关系：黑场是「分章」，调色是「让钩子看起来像片花」。要不要补进
  `out` 的选项（比如再加 `freeze` / `teaser_look`），等这条片子的实际观感定。

对照小样还在 `/tmp/bridge_demo/`（含 `http://127.0.0.1:8899/` 预览页，服务重启即失效）。
