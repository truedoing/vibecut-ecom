# 品类包说明 · 被讨厌的勇气（图书·心理自助）

> 本包是首个非食品大类包，兼作技能通用性第三验证点——它暴露的每一条 schema 摩擦都记录在文末。

## 一句话

把《被讨厌的勇气》的公开事实（出版信息 / 销量口径 / 核心概念 / 合规边界）整理成带货文案的只读知识层。素材模式与食品完全不同：**无厂商素材，四层重排为「通用书感库 25% / 单书素材 35% / 网络空镜 10% / AI 人群 30%」**，执行清单见同目录 `拍摄清单.md`。

## 素材方案：两层自拍 + 一层网络 + 一层 AI

| 层 | 内容 | 数量 | 复用性 |
|---|---|---|---|
| A 通用书感库 `GEN_*` | 翻页/台灯/便签/书堆/床头/撕塑封，画面里无可读书名 | 19 条 | **拍一次，所有书共用** |
| B 单书素材 `BK_bydy_*` | 封面/书脊/目录/版权页/金句页/划线/递书 | 24 条 | 每本书一次，约 25 分钟 |
| C 网络空镜 `NET_*` | 图书馆/雨窗/通勤/城市夜景（CC0） | 6 类 | 全品类共用 |

> **这是本品类的结构性优势**：书不是厂家特有产品，素材主体是「书这种物体 + 阅读这个动作」。
> 第 10 本书的边际拍摄成本趋近于 0——食品永远做不到这一点。

## 与食品包的三个本质差异（人审重点看这里）

1. **合规主战场换了**。食品防「身体功效」，图书防「心理疗效 + 数据出处 + 版本价格」。books 的红线写进 `compliance_ext.category_specific` 8 条：治好自卑/替代咨询/数据无出处/混版本报价/成段朗读/贬损他书/盗版引流/教育效果承诺。
2. **证据形态换了**。食品的「配料表/营养成分表」对应图书的「目录页/版权页/销量口径」；L1 事实=作者·出版社·对话体形式，L4=翻页便签等阅读动作，T2=日本 300 天榜首（可查记录）。
3. **AI 的可行性反而更高**。酱罐怕标签穿帮，书的封面文字同样锁死虚焦——但「翻动的书页/台灯/书桌」是通用画面，AI 生成比食品更自由。

## Schema 摩擦记录（本次验证的真实产出，已回写校验器）

| 摩擦 | 处置 |
|---|---|
| `source.type` 不认官方网络来源 | 校验器 STRONG_SOURCES 增加 `official_web` |
| `asset_index.mode` 只有两种 | 增加 `no_vendor_footage`（无厂商素材品类） |
| `vendor_assets` 键缺失即 ERROR | 图书包补空数组（结构保留） |
| proofs/trust 只认 level 枚举 | 图书包按 L1–L4 / T1–T3 重新标注 |
| status 枚举 ready/conditional/blocked | 与食品包对齐 |
| 七库没有人群维度 | `elements.audiences[]` + hook 挂 `audience`；人群由标的决定，不套平台惯例 |
| 素材只有「厂商给/竞品截」两种来源 | 四层重排为 通用库/单品/网络/AI，通用层可跨单品复用（食品 A 层不可复用） |

**结论：schema 骨架零改动可用，枚举层扩了 2 个值——「结构方法论 + 品类包」的判断在图书上初步成立。**
