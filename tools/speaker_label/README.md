# 台词说话人自动标注工具

给短剧每一句台词自动标上"谁说的"。给 4 个已知说话人的样本，模型按声音比对归类。**只产出数据表，不改任何片子。**

支持 Mac / Windows / Linux。换机器不用改代码，只改 `config.json`。

## 一、装环境（每个平台一次）

先确认系统有 **Python 3.10 ~ 3.12**（3.13 太新，torch 支持滞后）。

```bash
python setup_env.py
```

脚本会自动建虚拟环境、装 CPU 版 torch、speechbrain，走国内镜像。
**Windows 不用单独装 ffmpeg**——工具自带。`setup_env.py` 在 Windows 上用 `python`，Mac/Linux 用 `python3`。

没有合适 Python 版本时：Windows 去 python.org 装 3.11（勾选 Add to PATH）；Mac 用 `brew install python@3.11`。

## 二、改配置（只改 config.json 两处）

```json
"source_dir": "原片所在文件夹，比如 D:\\短剧\\以真心守护至亲",
"lines_dir":  "台词库 lines 文件夹"
```

Windows 路径写成 `D:/短剧/xxx` 或 `D:\\短剧\\xxx` 都行。模型默认从国内镜像下载，不用翻墙。

## 三、跑（两步）

```bash
python build_samples.py    # 第1步：用人工核准的样本做 4 把声纹尺子，并自检区分度
python label_all.py        # 第2步：全剧逐句比对打标签，支持中断续跑
```

产出在 `output/`：
- **说话人表.csv** —— 集 / 时间 / 谁说的 / 把握 / 台词 / 存疑标记。Excel 直接打开是中文。覆盖全部 60 集。
- **说话人表.json** —— 同样内容，程序读。

## 四、怎么用这张表

以后分析台词，直接读 `说话人表.csv`，按"集 + 时间"查是谁说的，不用再一句句听。
`doubt` 列标了两种存疑：**声音把握低**、**两人接近**——**这些句子要人工听一下**。没有存疑标记的可直接采信。

## 五、已知边界（如实说）

- **实测准确率约 73%**（用"留一法"测的：轮流拿一条已知样本当未知，看模型认不认得出）。
- 错的地方集中在**女儿许宁 ↔ 妹妹许晴**——两个年轻女演员声音接近。这两个人的句子建议重点听。
- 妈妈林秀兰（老年女性）和周承（男性）区分得很准。
- 画外音（旁白）能标，因为它也是同一个人的声音。
- 首次跑要下模型约 80MB（走国内镜像），之后用本地缓存，离线也能跑。
- 台词取自 `lines` 文件夹（覆盖 60 集）；每句按"本句起点到下一句起点"切音频，尽量不串音。

### 想提高准确率怎么办
换样本：编辑 `build_samples.py` 里的 `SAMPLES` 列表，切点必须落在"台词真实发声窗口"内、不能跨句。
判断样本好不好：跑 `diag.py` 看两两相似度矩阵——某段跟"自己人"相似度明显偏低（<0.2）就是切坏了，删掉它。
`leave_one_out.py` 给出留一法准确率，用来横向比较不同样本组合。

## 六、文件说明

| 文件 | 作用 |
|---|---|
| `config.json` | **唯一需要改的**：路径与参数 |
| `setup_env.py` | 跨平台装环境 |
| `common.py` | 公共工具：切片、声纹模型（模型下载走 hf-mirror） |
| `build_samples.py` | 做声纹尺子 + 区分度自检 |
| `label_all.py` | 全剧打标签，产出数据表 |
| `data/` | 样本尺子、断点缓存（可删后重跑） |
| `output/` | **交付物**：说话人表 |
